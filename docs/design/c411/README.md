| ---------- | ------------------------------------------------------------------------- | ------------------------------------------------------------------------------- |

没有选色点：当前左侧红/黄条、优先级颜色、状态圆形及工作项进度已经承载语义。再增加颜色点会加大学习和误读成本，因此两案都用固定中性色与可识别形状，形状不随着状态变化。

A 推荐仅为设计判断，不能代用户批准。B 的省略规则也只是本次候选；用户可选择 A 或 B，PM 必须携这同一版全部候选及附件交人。

## 4. 交互与可访问性

- 默认只有图标，不在三处界面增加模板名称小字。截图顶栏“设计样例”等属于审稿外框，不是产品页面文案。
- 悬停和键盘聚焦显示“模板：名称 · vN”；按钮可访问名称保持同样的完整信息，SVG 为装饰。实际项目模板 id 不在界面额外常驻展示。
- 点击/触控点按固定提示，再次点按、点外部、失焦或滚动关闭；Enter 同点击，Escape 关闭但保留按钮焦点。无长按依赖，无跳转或修改动作。
- 提示挂到页面浮层，按视口四边限制位置和宽度，长名称自然换行；不会被看板滚动区裁掉。不显示操作按钮，关闭无需额外小图标。
- 标记是开卡链接的兄弟元素，禁止在链接里嵌按钮。点标记只读模板，卡片原链接、标题与空白开卡保持原作用；实现时补相关回归，不扩大点击入口权限。
- B 省略默认模板时也不留不可见的 Tab 停靠点。详情保留图标及可访问全名。若卡片隐藏编号，标记保持类型信息组的位置；原型未做“显示”菜单，这一支路留给实现验证。
- 文字对比目标 ≥4.5:1，非文字图标/焦点 ≥3:1；命中区 ≥44×44px，视觉图形 16×16px，浅底/悬停底 24×24px。焦点是 2px 实线、偏移 2px。编号无下划线、常态边框、hover 内描边；键盘焦点保留。

## 5. 真实组件与实现交接

原型直接导入基线 `BoardCard`（含真实优先级、状态、工作项进度、等待/阻塞左条和附件图标）、`IdBadge`、`PriorityBadge`、`StatusTag`。新增标记只在独立样例包装层；列表与详情为按真实组件组合的设计上下文，**不是完整 CardListPage/CardDetailPage 的后端集成测试**。前稿使用同数据、同中性背景但无标记，供受控对比；不是生产截图，也不冒称完整原页面重现。

生产接入位置：`BoardCard.tsx`、`CardListPage.tsx`、`CardDetailPage.tsx`，以及 `CardTemplate.tsx` 已有模板信息区。只把重复静态模板名收进标记提示；该区任何现有合法业务操作和完成模式信息必须保留，不能随静态文案一起删除。

当前列表 `CardListItem` 未声明模板字段，正式实现需要根据已有授权响应接入卡片实际模板 id/版本/名称/内置身份；不得为每一张卡再请求详情，也不得从标题猜模板或推断门禁。图标查表以可信模板元数据为准。多处共用一套映射与提示行为，不能各写一份。

本稿只用 6px 控件/10px 面板圆角，审稿框按钮视觉 32px 高、命中区 44px；正文 14px，次级 13px，详情标题桌面 24px / 手机 22px；左右命中填充为 14px（16px 图标居中）。图标 stroke 1.6。看板列宽桌面 326px，窄屏卡宽 294px、可用页面 390px，列间 16px并露出下一列；页面外边距手机 16px，桌面 28px。普通列表行 58px；手机按信息分行。实际合并时优先引用 C-392 最终共享变量，偏差需重新截图确认。

本原型为了让独立标记 44px 命中区不与标题互相覆盖，把带标记卡的头行增至 44px。没有用透明命中区重叠邻近控件来假装保持密度；这个 20px 高度成本在前后稿中可比较。

## 8. 复现与附件顺序

仓库原型：按已有锁文件安装 web 依赖，运行 `node docs/design/c411/serve.mjs`；本机地址端口以脚本输出为准，入口 `/docs/design/c411/index.html`。查询参数：`variant=before|a|b`、`view=board|list|detail|legend`、`theme=light|dark`、`card=0..9`（详情）。`node docs/design/c411/build.mjs` 生成可独立托管的 `build/c411-prototype/`，入口仍在 `docs/design/c411/index.html`。浏览器截图需同时模拟对应系统亮暗媒体。

`capture.js`、`interactions.js` 是供当前 Playwright 工具执行的函数。将 `__OUTPUT__` 替换为本次可写证据目录（先建目录），在该本地服务上运行；测量结果由工具返回，写入 JSON。只用于设计截图/测量，不是项目 e2e 套件。

附件按以下顺序组织：设计说明；A 亮/暗总览；B 亮/暗总览；前稿亮/暗总览；24 张两方案三处固定视口原图；图例；全量截图和原始测量包；可独立托管的构建包。总览桌面画面缩放，细节以原图为准。截图包中 `-end` 是看板滚到末列，`-full` 是列表/图例全文，`-focus` 是键盘焦点，`detail-N-tip` 是边界提示。排除调试期间 `check-*` 图，不混用旧图。
