## 唯一结构及响应方式

| 顺序 | 完整详情页与抽屉共用内容 | 展示规则 |
| --- | --- | --- |
| 1 | 卡号 + 唯一完整标题 | 20px/1.45；手机18px/1.45。自然换行、连续英文断行，绝不截掉标题。抽屉关闭在右，完整页返回在左 |
| 2 | 状态 · 等谁 · 下一步 · 更新时间 · 风险 · 模板 | 有值才渲染，并据有效项插入分隔点；待明确、待规划等占位不显示。状态独立有字义，不用颜色代替文字 |
| 3 | 编辑、暂停、更多 | 一行44px；抽屉的完整页面链接在末端。不把取消卡片摆进主操作行 |
| 4 | 作者预检摘要（条件渲染） | 无记录完全不渲染；有记录为状态、短SHA、时间、日志入口一行44px，完整关联信息在日志层 |
| 5 | 概览 / 工作项 / 时间线等现有分区 | 紧邻上一区，8–12px间距；选中态为中性底色，无下划线。现有交付审核、附件、合并处理等分区有数据仍保留 |
| 6 | 当前页签内容 | 概览只包含目标、验收和背景等原信息，不再展示重复工作项折叠块；工作项只在专属页签，评论编辑器只在时间线 |

桌面抽屉宽760px、左右内边距24px、从视口顶端开始；手机满宽、左右16px，只有抽屉自身纵向滚动。完整页沿用项目导航；内容最大1088px，容器外边距24px、卡片内边距24px；手机直接满宽。设计只给容器示意，不重新设计全局页头、表头或导航。

元信息在1440px、760px抽屉均保持一行。390px可用358px，原型三个状态的内容宽度444/475/532px；保持单行并在该区域局部横向滚动，不裁掉字段、不缩小字号、不让页面横溢。区域可聚焦、拥有读屏名称，左右键按80px移动，Home/End到首尾，触控横滑可达。风险/模板会位于右侧，首屏不保证同时显示全部项；可达性需由实现验收继续核对。若上游最终采用自然换行方案，应重新交设计验收，不能把多行记录成一行。

标题过长只增加标题区高度，其余顺序不变。全空样本仅保留状态。已有阻塞原因、暂停原因/恢复条件、敏感后果、合并风险及权限拒绝必须继续完整展示在相关状态/操作上下文中，不能作为“说明小字”删掉。后台派生状态与权限仍由原规则决定。

## 交互与状态

- **更多**：包含复制链接、标为敏感、取消卡片。打开聚焦首项；上下键与Home/End导航；Escape关闭并回到更多，Tab退出关闭菜单。复制/标敏感原型只给明确演示反馈，不操作真实剪贴板/数据。敏感切换沿原业务资格和提示，不能添加或取消原门禁。
- **取消卡片**：先打开危险确认层，保留卡号上下文、状态后果、可选原因、“返回”和“确认取消”。取消/关闭/Escape不提交；确认后仅演示反馈。正式实现保留原请求、幂等、防重及错误处理；终态仍按原规则呈现“标记被取代”等适用动作，不能强行出现取消。
- **编辑/暂停**：保持可见入口；原型演示标题、目标、验收、优先级和暂停原因/恢复条件。暂停层保留“不派发新工作，已有结果保留，正在执行工作可完成”的必要后果。实现复用完整原表单；已暂停时保留修改信息/解除暂停，人工完成模板仍保留标记完成及条件；这些低频动作可进入更多，但资格与原因不变。
- **背景**：概览中目标/验收之后，一行“背景 · 来源原话 · N张相关卡片”，默认折叠。展开显示完整原话和无下划线的编号链接；无来源/无关联则相应部分不显示，全空不渲染背景。原型3张卡各有1条来源/1个关联，没有使用生产原文。
- **预检**：短SHA用于扫描，点击日志可读完整SHA、执行时间、结果和明细；正式实现保留每次检查的关联关系，不把作者预检称为审核通过。进行中、失败、不可达使用原状态词和语义色；没有预检完全无占位。原型只演示通过记录和日志层，不覆盖所有检查状态。
- **工作项/时间线**：方向键移动并选择页签，Home/End到首尾，Tab进入内容。工作项在专属页签显示进度；时间线保持原排序、内容和筛选。唯一评论框与发表按钮位于时间线；失败保留草稿，不出现虚假成功。其它深链接仍定位同一编辑器；附件、Markdown、@提及等能力由原编辑器提供，原型未重做。
- **抽屉**：打开焦点进入关闭按钮，Tab不进入遮罩后的内容；Escape关闭并返回合成触发卡片。嵌套菜单/对话框优先处理Escape，关闭后回到各自触发按钮。实现保留当前共享Drawer与C-377焦点修复，避免重新挂载表单导致焦点掉到body。
- **通知**：复用C-392顶部居中浮层规则；不占文档流、不留常驻空白条，可覆盖非交互标题，避开关闭/返回/主操作/页签。短内容最多两行，长错误可点击44px“详情”入口打开完整文字层；错误一直保留到关闭。成功默认5秒，悬停、聚焦或打开详情期间延后消失；加载由真实请求结束，原型模拟状态不代表后端成功。并发队列、配置接线由共享通知实现，不能在本卡另做通知系统。
