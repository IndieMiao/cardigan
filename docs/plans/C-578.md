# C-578：清空卡片截止日期

- `updateCard` 与 MCP `update_card` 共用三种更新语义：省略不改、传日期设置、传 `null` 删除文档字段。沿用 PM／人的权限与状态转换规则，不改建卡行为。
- 在同一笔 `card_updated` 事件和时间线里记录截止日期变更；与其它元数据一起更新时保留原有说明。重复清除不再宣称日期发生了变化。
- 人类 CLI `card update --deadline YYYY-MM-DD|none` 走同一领域命令。看板摘要不展示截止日期，详情读取当前卡片文档；不增设界面控件或提示。
- 通过领域契约验证设置、保留、清除及状态不变；验证 MCP／CLI 入口、持久化回读和时间线。运行相关测试、domain 测试类型检查、lint、依赖检查和远程预检。
- 真实数据不随发布或测试改动。上线后由张良在森森项目用新入口清除 C-14 的截止日期，回读确认后在 C-14 回帖。
