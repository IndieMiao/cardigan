# C-742 交给张良（主机操作员）的人工待办

## 模型

- `HumanAction.executor?: "owner" | "operator"`，缺省为 owner。与 `triage`（谁分拣、是否交主机）正交；PM 分拣改写保留执行人。
- `request_human_action` 新增可选参数 `executor`。不填时按规则 1 推断（`inferHumanActionExecutor`）：
  - 标题（指令第一行，或改写后的 handoff 标题）以 `张良：` / `张良:` 开头；
  - 或 `why_human` 含默认关键词：`张良`、`主机`、`凭据文件`、`OSS`（不区分大小写）、`送签`、`云助手`（`OPERATOR_ONLY_KEYWORDS`）。
  - 显式参数优先，所以 owner 待办即使写到主机，也可以显式标成 `executor=owner`。

## operator 待办的行为

| 面 | 行为 |
|---|---|
| 飞书外发 | `extMessageItems` 跳过；飞书卡片只读 |
| 应用内门铃 | 不响 needs_you，只给 PM Office 发一条“等张良执行” |
| Needs You 计数 | 不计入 `total_pending` 和待办 attention |
| Workbench | 单列为“交给张良”，状态“待张良执行”；不显示完成表单，只给“改由我处理”按钮 |
| 卡片等待项 | “等待张良执行 H-n” |
| 结项 | 只有张良的身份（项目内有效的外接常驻 PM Office，角色带 `complete_host_action`），或 `cardigan human-action done --operator`（人类 CLI，直接写主机库）可以结项；Web 和飞书以普通人身份提交，会被拒绝。PM Ops 的 `triage done` 也会被拒绝。系统自动结项（部署、上下文巡检）不受影响 |
| 改派 | `reassignHumanAction`：人（Web `POST human-actions/:id/reassign`、CLI `human-action reassign`）或常驻 PM 可以改派；改给 owner 后按普通待办推送和计数 |

## 张良可监听的事件

请求或改派为 operator 时写入 `operator_action_requested`（events 表，带 card_id）：
`{ human_action_id, executor: "operator", reason: "requested"|"reassigned", title, instructions, why_human, expected_return, ready_when? }`。
`human_action_requested` 的 payload 同时带 `executor`；改派写 `human_action_reassigned`。

## 迁移

迁移 `1795585467683_operator_human_actions` 的钩子按规则 1 回填仍未结、非系统发起、未显式设置执行人的待办。迁移不补写 `operator_action_requested` 事件：这些待办本来就写给张良，张良能在 Workbench 的“交给张良”里看到。
