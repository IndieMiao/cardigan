# C-409 侧栏构建版本

目标：在 Cardigan 侧栏标题下显示当前服务构建的七位 SHA 和本地时间，悬停查看完整值，点击复制完整 SHA。

## 实现

- 服务启动时从自身代码根目录解析 Git HEAD，支持 detached、普通分支及 worktree；只接受完整四十位十六进制 SHA。self-deploy 的 release 目录名与 SHA 相符时作为发布构建，其余显示开发标记。无 Git 时显示 `dev`。
- 构建时间取当前代码根目录内 `apps/web/dist/index.html` 的修改时间，不读取部署状态、生产目录或私有配置；文件缺失时不编造时间。不修改发布流程，也不将服务重启时间称作部署时间。
- 通过现有 `/api/session` 已登录响应附加版本，只返回 SHA、ISO 时间与开发标记；服务实例内固定，页面刷新重新取得版本。未登录不提供版本。
- 桌面侧栏与窄屏导航抽屉复用紧凑版本行，中性次要文字，无链接或说明段落；收起抽屉时随侧栏隐藏。悬停/聚焦显示完整 SHA 与明确标注的构建时间；复制结果就地反馈。

## 验证

- 服务端单测覆盖发布构建、开发分支/worktree/packed refs、无 Git、缺失构建文件及会话接口隐私/缓存。
- 前端相关单测覆盖本地时间、完整 SHA 复制、失败反馈、开发降级与会话到侧栏的数据传递。
- 使用现有本地合成 App 夹具提供 1440×900 和 390×844 亮暗截图，包含窄屏导航展开/收起，检查无页面横向溢出。截图是非生产规模的布局证据。
- 运行增量构建、相关测试、`pnpm lint`、`pnpm check:deps`；本地 commit 后请求同 SHA 远程预检，再交付给 W-1410 审核。
