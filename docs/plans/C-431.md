# C-431：Linux worker 接入向导

对应 `agent-worker-wizard.md` P1 与 Linux 准备部分，按本卡范围收窄；不实现 macOS、自动资源配置、Workbench 或远程派发开关。

- CLI 提供人专属 add/resume/check/status 和纯预览 dry-run；非交互读取私有 YAML，复用 machine register 的领域校验和事务。新机器 offline，重复执行保留现有状态。
- host 负责编排与日志，复用已有固定目录 FD、0600 文件、原子发布/fsync 和 flock 原语。整个向导目录串行，使不同机器编号的草案也不能并发认领同一 SSH 目标。journal 和配置草案分开；配置摘要变化拒绝复用，人工归档后重新登记，旧 Assignment 不改绑。
- runtime IO 复用严格 host key 的 agentProcessCommand。固定只读 Python 探测不读取凭据、忽略 stderr，只返回固定成功标记；超时默认 15 秒，可设 1–60 秒；输出上限 4096 字节。hc 默认发行清单版本，Node 至少 24、pnpm 主版本 11。Linux 的 SSH 当前进程及祖先 cgroup 必须有有限 CPU/内存/任务数上限，现场 hc 归属与 CI 共存另验。
- 复用 Linux 安装器的操作员入口，root 准备只输出命令。helper 校验同发行文件摘要和保护目录，拒绝不同版本。
- RW-2 尚未合入当前基线。此版使用向导私有 mcp_url，探测 HTTPS `/mcp` 的未鉴权 401；不带 Token，不代替 RW-2 的真实启动鉴权。根据 RW-2 的已交付合同，草案包含项目级 mcp_url/mcp_timeout_ms；旧解析器环境仅在草案校验时剥离已独立严格校验的 MCP 元数据，运行时接线仍由 RW-2 负责，正式加载前必须部署 RW-2。发布限额要求显式填写，推荐头 64 KiB/单文件 1 MiB/批次 8 MiB/30 秒；试点 run-capacity.yaml 同时设 limit/max_limit 为 1。账号及根使用 cg_<项目短码>、/srv/cardigan-workers/<项目短码> 的推荐约定，不强制迁移。
- 相关测试位于 `apps/cli/src/worker-wizard.test.ts` 和 `packages/host/src/worker-onboarding.test.ts`；覆盖 Token 拒绝、预览无副作用、真实登记幂等与 draining 保留、各步失败续跑、持久意图、冲突、链接/权限/截断/并发及实际 Python 探测程序。只跑相关测试和增量构建，未改 domain，不跑本地全量或 e2e。

用户操作指南见 [接入一台 Linux worker](../linux-worker.md)。真实 Linux worker 与 CI 共存未在作者会话执行，软件验证和现场证据分开报告。
