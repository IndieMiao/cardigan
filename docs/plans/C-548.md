# C-548 管理员接入后的 worker helper 升级

- 未接入的绑定沿用 C-538 人工待办。接入以控制主机私有配置为准，只在后台巡检处理；不修改 worker 发布协议和调度开关。
- 用独立于 SSH 身份的发行签名验证固定清单，只从部署状态指向的本进程发行版取三个文件。上传使用标准输入，不解包、不接受远程路径或命令。root 入口及安装检查器由管理员首次安装，与上传文件物理分离。
- 特权端核验身份、签名、时效、目的绑定、文件集合、摘要、目录与权限；保存旧文件后逐文件原子替换，用固定检查器只读验收。后台先登记持久停派，依次验证 worker 和 machine，均通过才解锁；失败去重、审计并通知主机运维。
- 交付双平台一次性接入与验证命令，现场待办合并后才生效，不以模拟测试代替现场结果。按 Q-1078 修改仓库规则；不操作真实机器、账号或凭据。

复审修订：升级停派只能由同一检查任务、绑定和版本的最终机器检查事务解除；新 worker 检查开始即作废上次半份人工证明。撤销接入后旧版本停派转为当前版本人工双检查，不触发写入；已接入机器也必须有本轮 helper 不符证据才安装。首次授权前核验入口与固定检查器的实际写权限，准备/激活密钥前核验服务私有目录与已有文件。
