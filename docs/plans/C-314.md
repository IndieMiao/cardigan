# C-314 执行视图四项改进

赵云按卡片验收标准实现，仅修改 Web 展示与本地偏好。

- 时间：未来值仅在浏览器当前本地日历分钟内显示“刚刚”；过去不足 60 秒沿用“刚刚”，其余相对时间、完整日期、时区提示和无效值保持原规则。
- 默认表格、不分组、最近活动从新到旧。760px 及以下保留原紧凑列表；按员工分组时分组可折叠，卡片模式始终按员工分泳道，窄屏纵向堆叠，宽屏在列表区域横向滚动。
- 分组使用员工编号，名字相同但编号不同不合并；缺少员工信息归入“未分配员工”。计数只统计筛选后的 Assignment，运行中计数只读取现有 running 投影。组次序按当前有序集合首次出现，组内保持同一排序。
- 状态顺序：运行中（running）→排队中（provisioning、原排队 Run 或 queue_ahead）→失联/未知（lost、unknown 及未识别状态）→空闲（idle、not_provisioned、外接身份）→已结束（released，兼容 done）。不从历史 Run 成败推断当前 Assignment 已结束。两种排序互斥，同状态稳定保留最近活动默认顺序及既有容量队列次序。
- 复用身份、任务链接、状态、上下文、运行配置、活动时间和详情抽屉；卡片使用既有 card-tile 基础样式，局部覆盖长标题换行，不改变 BoardCard 或看板业务。
- 模式、分组、排序沿用本浏览器 localStorage 和项目分区，属于当前浏览器用户的偏好；没有服务端用户编号，不新增用户接口，不使用会话 read_scope 作为持久用户身份。不同浏览器用户空间互不影响，刷新保留选择，存储不可用/损坏回默认。

验证：Web 包 vitest（单 worker），改动文件 Biome、diff 检查、Web TypeScript 与构建、依赖方向检查；本地合成夹具 1440×900 / 390×844 亮暗布局及键盘/触控目标核对，不连接业务服务。正式设计验收由同卡验证项对当前完整 SHA 执行。主机远程预检需绑定交付 SHA，不由本地测试替代。

首轮布局结果（提交 2e5140b7，仅原四项）：上述两种宽度与两种主题，每种检查表格、分组、折叠、卡片、状态排序、抽屉，共 24 个场景。页面均无横向溢出；宽屏泳道可视宽 1172px、内容宽 2378px，窄屏可视与内容均为 366px。交互目标最小 44×44px；正文对比度亮色 15.67:1、暗色 9.91:1，次要文字在卡片与页面底色上最低 5.42:1。键盘展开/折叠与排序、窄屏触控切换卡片、Esc 关闭抽屉后焦点返回均通过。该记录使用固定的 8 个 Assignment / 4 个 Run 小规模合成夹具，不代表生产规模或性能验证；截图与测量随卡片附件提交。

## 追加范围（卡片 #41，R-6404）

- 抽出共享表格按字段分组组件。执行表格按员工分组，卡片列表在“显示”菜单选择状态字段分组；默认不分组，选择按浏览器用户空间与项目记忆。组内沿用现有排序，组名与数量、折叠行为共享；数量只统计当前筛选/分页后的已显示结果，不额外拉取数据或改变分页。
- 执行页的下拉框、条件标签和计数在宽屏同一行，窄屏按可用宽度自然换行。默认工作中，下拉框只保留一个全部，清除条件返回全部；共享筛选栏其它调用方保留原默认行为。
- 全站页面标题中的容量入口去边框与底色，保留详情弹层、键盘焦点及至少 44×44 的交互范围。
- 设置页重设计和全局去青色不属本卡；与 C-386 依最新主机基线处理共享列表冲突。新增共享组件、卡片列表分组和筛选边界测试，重跑 Web 包及两种宽度/主题的布局检查。

扩展版验证：Web 包 71 个文件、1014 项测试通过；共享分组、卡片列表、筛选、分页、共享时间与容量组件的定向 6 文件/88 项通过。真实浏览器证据扩展到 40 个场景，增加紧凑筛选、卡片列表分组菜单/分组/折叠；两种主题容量入口均为零边框、透明背景，宽屏筛选/条件/计数同行，390px 分组折叠按钮在可视区域内。执行页和新增分组菜单/按钮最小目标 44×44；旧卡片列表其它控件没有在本卡统一改尺寸。无接口、权限或调度规则变更。
