# C-459：Needs You 各标签页统一列表行

依据 `docs/design/ui-guidelines.md`（卡片页为基准）。只改界面，不改接口、权限、写操作或敏感卡规则（Needs You 前端本无敏感卡分支，显示内容仍由服务端决定）。

1. 新增共享布局 `components/layout/NeedsRowLayout.tsx`（配对 module CSS，只用 token）：`NeedsList` 分组框与组头栏（批量操作位）、`NeedsRow` 行（左：卡号 + 事项编号 + 标题/人话概述；右：时间、状态、主操作；行首箭头展开详情）、`NeedsOpenAction`“处理”、`NeedsListFooter`、`NeedsNotice`。
2. Needs You 的拍板、拍板落实、合并确认（含 PM 代确认）、待你执行（含待主机操作、执行结果）、运行异常、审核恢复异常、指派与催办、稍后、知会全部改用上述行；详情里保留原表单与写操作。卡片详情的合并确认保持原布局。
3. 组内说明小字和空状态说明句移到帮助页；空状态统一为“没有需要你处理的事”。删除不再使用的 legacy 样式（只删不增），并删除已迁移原生按钮的存量豁免。
4. 规范补充“Needs You 行模式”与验收清单一项；用合成夹具 `test-support/needs-you-fixture.tsx` 和 `needs-you-screenshots.mjs` 生成前后 1440/390 × 亮/暗截图、与卡片页同宽同主题并排图及测量。共享视觉基准 44 图保持零像素差异。
