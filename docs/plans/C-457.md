# C-457：拍板记录页按设计规范重构

依据 `docs/design/ui-guidelines.md`（卡片页为基准），只改界面，不改接口语义和权限。

1. 页面骨架：`ui-workspace` + `PageHeader`（标题、已加载条数计数，有下一页时显示“N+”，右侧沿用容量摘要）+ `PageToolbar`。
2. 工具栏左组：决定人、类别（`FilterSelect`）、卡片编号（`SearchInput`）、开始/结束日期（新增共享 `FilterDate`）；右组 `RefreshGroup`（默认 30 秒，按项目持久化，pending 不重复请求）。原有五个筛选、路由持久化、日期按本地日界转换全部保留。
3. 列表：`DataTableLayout stacked` + 共享表头/单元格。列为编号、问题、状态、所选方案、决定人、类别、卡片、记录人、拍板时间；≤640px 沿用卡片列表纵向记录。短值列用新增的 `DataTableCell nowrap`。
4. 详情：点击问题打开 `Drawer` + `CardDetailLayout`，显示元信息、须亲自决定原因、人话概述、原始背景、全部选项（推荐/已选）和结果（所选方案、理由、授权依据、记录人）。打开的记录写入路由 `decision`，不参与服务端查询；关闭后焦点回到原行。
5. 分页：保留“加载更多”与刷新时重读已加载范围的逻辑；底部沿用卡片列表分页栏样式。
6. 清理本页 4 条旧控件豁免（`ui-legacy.json`）；规范补充日期筛选与非卡片数据表两种模式。
7. 证据：`test-support/decision-history-layout.mjs` + 合成夹具，1440/390 × 亮/暗，前后截图、与卡片页同宽同主题并排图和测量。
