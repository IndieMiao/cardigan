# C-545 可复制的人工操作命令

1. 为人工待办增加可选的结构化终端步骤（目标、登录方式、原样复制的命令、预期输出和失败处理）。请求和 PM 改写均可填写；Needs You 展示代码块，复制不执行命令。更新默认 PM、主机运维角色规则。
2. 只在受信目标的 helper 版本或摘要明确不符时，从控制主机自身发行目录备料，以现有项目 SSH 身份在临时目录暂存。人核对目标、暂停派发并确认无活跃任务后，复制命令，在 root 私有目录校验固定摘要后安装。暂存失败不给可执行命令，下次巡检重试；不改 helper 协议，不自动使用 sudo。
3. helper 待办绑定项目和机器；人在 Needs You 确认时顺序运行已有 worker check、machine check，以主机返回的两项检查结果回填。失败保持打开，不接受文本、客户端布尔值或分拣结项代替核验。普通待办不变。
4. 用合成发行材料、临时目录和模拟机器检查验证两种平台的命令、复制、核验成功/失败、幂等和旧数据兼容；不操作生产机器。
