# C-469：候选树重拍界面基准

- PNG、测量和源码清单是派生物，不参与三方合并。保留原有 44 个场景和固定浏览器；每次从实际检出的代码重拍。Git 只存设计认可的图片散列，首版沿用既有图片，不把本次迁移当作外观授权。
- 新授权只新增本卡的稀疏记录，不覆盖其它卡的文件。按场景选择最高代；同代相同认可可合并，不同认可或未见过的合成效果不能冒充已验收，需要在新基线上核图。源码冲突仍按原流程处理。
- 候选检查校验实际渲染；main 用同一命令生成、校验并保留按完整 SHA 命名的图片和测量。规范说明改前、交付、候选和最终版本的证据对应关系。
- 用临时 Git 分支演练两个并行交付、真实浏览器重拍迁移前后、检查缺图/旧图/真实设计分歧。跑定向测试、增量构建、lint 和依赖检查。
