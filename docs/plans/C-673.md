# C-673 看板依赖连线加流动光点

所有者要求（附件 board-dag-flow.png）：给 C-668 的悬停依赖曲线加上沿线流动的光点，方向与箭头一致（前置卡 → 后续卡）。状态与保存：无写入。

## 设计

| 项目 | 做法 |
|---|---|
| 方向 | 每条线的路径本来就从前置卡起、到箭头止（`from>to`），光点从路径起点向终点移动，与箭头同向。 |
| 光点 | 每条线另画一条同形路径，用零长度虚线段加圆端点画点：`stroke-dasharray: 0 间距`，`stroke-dashoffset` 递减使点向终点移动。点直径 4px（`4 × --ui-stroke`），不加箭头。 |
| 数量与间距 | 每条线按长度分成约 240px 一段：`round(长度 / 240)`，限 1–3 个，间距 = 长度 / 个数，均匀分布、首尾衔接循环。 |
| 速度 | 所有线统一 64px/s 匀速（`requestAnimationFrame` 按帧间隔推进；单帧最多推进 100ms，切回后台再回来不跳）。重绘（滚动、尺寸变化）后保留每条线的相位，只按新长度取模，光点不重置、不跳动。 |
| 颜色 | `color-mix(in srgb, var(--ui-border-hover) 60%, var(--text))`：亮 `#808080` / 暗 `#898989`，比线（`#bcbcbc` / `#505050`）稍明显，仍介于背景和文字之间；随连线层按主题混合（亮 darken / 暗 lighten），经过文字时文字像素不变。 |
| 播放时机 | 只在连线显示时（悬停或键盘聚焦）挂载并播放；连线隐藏时整个连线层卸载，动画循环随之取消。 |
| 减少动态效果 | `prefers-reduced-motion: reduce` 时不渲染光点路径、不启动循环，只显示静态线和箭头；运行中切换系统设置会即时跟随。CSS 另以媒体查询隐藏光点作兜底。 |
| 性能 | 每帧只写每条线的两个属性，不读布局；不新增监听。 |

## 实现

- `src/board-dependency-flow.ts`：`curveLength`（三次贝塞尔长度）、`flowDots` / `flowGap`（个数与间距）、`advanceFlow`（推进相位）、`flowDash`（虚线属性）。
- `src/useBoardDependencyFlow.ts`：`useReducedMotion`、`useBoardDependencyFlow`（帧循环，挂载时运行、卸载时取消）。
- `components/layout/BoardDependencyLayout.tsx` / `.module.css`：线之后画光点路径和样式。
- 证据脚本 `test-support/c673-capture.mjs`（复用 `c659-fixture.tsx`；夹具加 `?dense` 给 C-23 增加 6 条依赖，用于性能测量）。

## 已知取舍

- 光点每帧由主线程写属性（与 CSS 虚线动画同样走重绘）；10 条线同时显示、看板横向平移且各列滚动时实测 60fps、无超过 25ms 的帧。
- 很短的线（< 120px）也有 1 个点，速度与长线相同，所以一圈更快。
