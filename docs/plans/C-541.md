## 取证边界（审核返工）

- 同一 Run、会话与终端代次内，已核实的进展按原时间保留一个宽限期。会话和终端同时复查时，任一侧超时或读取失败，另一侧的旧证据也不能确认停滞。只靠终端或文件静默产生的告警供运维查看，不作为上游聚类或重启依据。
- Claude 的用量仍只读原 4 MiB 尾窗。告警读取可在窗口前补最多 64 KiB，按完整记录分辨主线程与旁支；无法归属的截断行不用文件时间补猜。纯计时、错误和旁支都不刷新时间，也不抹掉此前已知的主线程进展。前台命令的启动和结果必须出现在可连续核对的记录中，复杂 shell 文本只报告 Bash，不解析参数里的服务名。
- 对已定位的同一前台 Bash 调用，只用可核实的累计输出字节数或行数增长刷新告警进展，取增长记录自身的时间。计时、计数重复或回退、无关调用不续期；不从输出正文推断，不向外传递正文或计数。
