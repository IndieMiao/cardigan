# C-519 · 浏览器能力与 Run 使用同一安装位置

- 在 MC-1 的能力探测中优先检查 `launch.yaml` 的 `browser.browsers_path`，再查原有系统命令、Chrome.app 和 Run 账号的缓存。路径作为参数传到已解析的本机或 SSH 运行目标，不在控制端展开或执行浏览器。
- 巡检使用 server 已接受的启动配置；CLI 使用同一启动配置读取入口。不读浏览器凭据，不安装软件，不改变选机规则。
- 在本次健康快照中单独记录浏览器探测失败的排查位置，不把浏览器缺失当作机器离线。只用配置键、命令名和账号相对路径，不保存主机私有路径或进程输出。
- 用合成浏览器和账号环境验证版本、优先级、回退和失败快照；更新 Linux 和 macOS worker 指南。
