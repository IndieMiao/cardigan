# C-476：核实未派发后释放检查占用

1. 复用原派发摘要和 GitHub 完整分页发现。只接受已放弃、没有运行编号、没有在途派发且在发现期限之后开始的核对；提交结果时在事务内重新核对登记。保留原记录及原因，不删除分支、不写检查通过、不重新派发。
2. 同卡预检等待事件指明占用的 attempt，相同等待去重。C-466 的退避仍适用于限流、查询不完整或身份不确定，核实未派发不是错误。
3. 人可用 `cardigan merge finish-undispatched <C-n> <attempt> [--project <p>]` 请求同样的在线核实；无强制或跳过核实选项。旧记录（包括 C-308）随部署走同一条恢复路径，现场只核对事件，不直接操作生产库。
4. 隔离验证自动释放、同卡再次准入、等待去重、并发保护、CLI 身份及拒绝未核实；运行增量构建、相关单测、lint、check:deps。
