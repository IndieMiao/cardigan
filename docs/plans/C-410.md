# C-410：看懂卡片

## 范围与依据

按本卡验收增加帮助页图例，不改卡片视觉信号、权限、流程或开发方案正文。依据 `BoardCard`、`Priority`、`StatusIcon`、`CardHoldDetails`、`styles.css` 及服务端工作项进度读模型逐项核对。

## 实现

1. 增加“看懂卡片”帮助目录项，真实 `BoardCard` 示例配编号标注；示例为合成数据，不跳转到真实卡片。
2. 按左条、状态、优先级、进度、元信息、暂停/等待/取代分组列“元素 → 含义 → 什么时候出现”，复用真实图标、进度和主题类。
3. 检查全部看板状态、优先级、状态修饰类和卡片可见信号的图例覆盖；组件旁保留同步维护注释。
4. 复用帮助页布局，窄屏表格折为有字段名的纵向条目；仅帮助页新增说明。参照 C-392 的紧凑、少装饰、共享主题规范，不引入新的输入控件或全局控件样式。

## 验证与交付

- 运行 Web 相关单测（含既有快照）、增量类型/构建、`pnpm lint`、`pnpm check:deps`。
- 使用本地合成夹具截取 1440/390 亮暗帮助页，核对无横溢、真实组件、标注、各颜色和窄屏表格；不运行本地全量或端到端测试。
- 本地提交后申请远程预检，同 SHA 通过后交付给本卡代码审核项。截图和测量作为附件，设计验收依据本卡标准及 C-392 控件规范。
