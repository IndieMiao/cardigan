# C-436 执行视图迁移

按 `ui-shadcn-migration.md` 第二阶段迁移执行视图，复用卡片页的页头、筛选行、表格、分组、卡片容器、状态 tooltip 和详情布局，不新增 CSS。

1. 使用现有执行接口的机器登记、Assignment 绑定及 Run 派发快照。机器标签优先登记名称，未知值保留原编号；历史 Run 优先自身快照，缺记录时显示未记录，不用当前运行环境猜测历史事实。常驻角色按实际运行绑定展示。
2. 保留表格、分组和卡片模式、排序、抽屉与运维命令；显示菜单切换员工/机器分组，机器筛选进入 URL。搜索覆盖员工、编号、任务、机器。刷新默认关闭，保持既有 SSE 更新；可选 10/30/60 秒或 5 分钟，设置按项目保存在浏览器。
3. 页头复用容量组件，执行页展示各机器非常驻占用/上限，详情保留全部占用、队列和常驻不占额度的口径。状态原因、排队顺序、超时和会话维护放进可聚焦 tooltip。
4. 删除执行页独占旧 CSS 与防回退豁免。用固定 8 个 Assignment、4 个 Run、4 张卡、2 台机器的合成夹具记录三种模式、两主题、两宽度改前改后及卡片页/详情页对照；验证操作区不移动、键盘、筛选、分组、容量与 axe。
5. 本地仅运行相关 web 测试、增量构建、lint/check-ui 和 deps；提交后请求同 SHA 远程预检，通过后交代码审核与界面验收。
