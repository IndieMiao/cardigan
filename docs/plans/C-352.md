# C-352 多标签页列表读取补齐

作者：赵云。基线 `cbd0c094d69499a4e077c4aa1b80226862546baa`，按本卡恢复排期说明只实现一期剩余部分。

## 覆盖与计划

- C-386 已实现默认 30 秒刷新、列表分页增量、按查询的短时缓存，以及隐藏时跳过定时读取；C-399 已补审核索引与关联查询。沿用这些行为，不重复实现。
- 增加经过现有 Web 会话及项目校验的 `/cards/version`，与列表在同一事务中使用相同版本依赖。版本查询不加载卡片或派生投影；版本包含查询、会话读取范围、项目和队列依赖，不能跨会话复用。仍为仅供人使用的 Web 接口，MCP Token 不能读取。
- 客户端已有当前页时先读版本；相同则复用内存中的页面，变化才请求已有增量接口。筛选、分页、排序、删除及归档继续由原分页合同处理。SSE 仍只记录变化，遵守 C-386 默认 30 秒和关闭选项。
- 隐藏时暂停列表及泳道偏好读取；回到可见时补读一次，包括关闭定时刷新的情况。正在处理的 HTTP 不强行撤销，后续展开页请求检查可见性。
- `view=summary` 用明确的卡面字段集合投影，去除正文、检查历史及其它详情字段；完整列表兼容入口和按需详情保持原合同。保留卡面、员工提示、暂停原因、排序及计数所需内容。

## 验证范围

定向运行 server 版本/缓存/分页/鉴权及列表读取测试，web 缓存、列表筛选排序、可见性、看板分页和 SSE 直接消费者回归；增量构建、lint、check:deps。不改 domain，不运行本地全仓/E2E。提交后执行同 SHA 远程预检，申请代码审核、独立复核及设计验收。

性能只用 C-287 生成器的合成数据，固定种子 352；规模至少达到 C-399 已公开的 399 卡、104806 事件等统计，记录真实生成数量。模拟五标签、每分钟七次正常变化，分别记录五页可见与一页可见的同步读取总耗时、列表调用数、事件循环最大延迟。使用模拟业务时钟和串行有界请求，不造空转负载。公开统计是历史基准，最新生产规模及生产 CPU 低于 20% 尚未核实；部署后现场观察由既有 H-113 跟进。

二期 SSE 按项目合并查询不在本次范围；不读取生产数据库或附件。设计与测量留在本文件，不修改开发方案正文。
