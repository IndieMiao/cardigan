# C-312：Needs You 分类标签、按需加载、系统知会与接手确认

初版接手提示已提交于 `cb551123`。新增范围依据 C-312#51 的用户授权及 #54–#58 更新的正式验收；保留初版交互，新增下述只读数据路径和标签。旧角色预检能力依 Q-761 等受支持升级方案恢复，不改变流程版本或交付门禁。

## 分类与读取

- 固定顺序：待拍板、合并确认、待你执行、稍后、知会。默认第一个数量非零的标签，全空选待拍板。手动选择后不因数量变化强制跳转。
- 计数使用独立的 `/needs-you/counts`，导航也只读计数。内容使用 `/needs-you?section=…`，只构造当前标签的决定/合并证据、人工事项、异常、稍后或知会。未指定标签的旧全量接口和 MCP 查询保持原行为。
- 计数与内容共用领域层原资格选择：拍板落实归待拍板；PM 处理中合并归合并确认但不增加人的待办数；主机事项、运行异常及需安排事项归待你执行，主机事项不增加人的全局待办数；稍后数量不标待办；知会显示总数，以未读数量突出。
- 计数不读取决定正文、不构造合并详情。只读快照仍复用原 Store 缓存，资格与时间边界每次重新校验；不新增数据库、后台轮询周期或授权规则。
- 第一次选中标签才加载。已打开面板留在内存保留草稿，隐藏面板不刷新；重新选中时取当前数据。复用原会话/项目/服务端版本的共享读取协议，计数与不同标签使用不同键，迟到响应不覆盖其它标签或项目。会话退出/项目切换按既有边界失效。
- 保留原知会分页和已读操作。知会类别按持久事件、处理者及代理来源区分：自动合并开关、超时代批、其它系统规则合并、系统维护、PM；不从中文正文或仅凭 system 身份猜测“超时”。
- C-392 的 D-1409（V-1737 通过，设计规格附件3964）已可用：标签沿用主题变量，以中性底色、加粗及底部短标记区分选中；桌面单行，手机五列且名称/数量上下排。未读取计数时用占位，首次内容加载用骨架；知会按来源身份/标题、处理方式/时间、关联链接/依据、已读动作排列，未读有明确文字。全局主题、页头及通知仍由 C-392 统一，不在本卡复制全局实现。

## 接手确认

- 在现有 PM 合并项显示“接手处理”。点击后用现有 Radix Dialog 显示“这条由 PM 处理即可，确定要接手吗”，提供取消、关闭和确认接手。初始焦点在取消；取消、关闭、Escape 或遮罩关闭恢复入口焦点。
- 基线没有独立接手接口。确认接手仅在本页展开原合并、暂缓、退回和建议操作，不改变处理方，不自动发起合并。之后沿用原写入、幂等、防重复及错误反馈。新的确认版本重新提示。
- 检查开启且尚无结果或仍在排队/运行时提示等待。原确认合并禁用条件、强行确认入口及后端门禁保持。
- 仅 Needs You 的 PM 分组启用；普通人的确认和卡片详情保持原交互。复用现有分组、计数与展示偏好，不增加存储。
- 运行 NeedsYouPage、CompactMerge、DecisionSuggestion 及直接调用方组件测试，改动文件 Biome 与 web 依赖检查。浏览器仅用隔离合成夹具验证 1440×900、390×844 亮暗主题；不运行全仓或端到端测试。
- 提交完整 SHA 后按原流程做远程预检、代码审核及设计总监正式验收；不以本地截图替代正式 Review。
