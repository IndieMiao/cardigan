# C-731 常驻 PM 可只读查询能力使用说明

来源：C-724#11 已知缺口；前置 C-726（`get_capability_guide` 只读工具）。

## 改动

- `packages/domain` 的 `STANDING_ROLE_TOOLS`（默认 pm 角色包与 standing 类型白名单上限共用）新增 `get_capability_guide`。`standingTools` 对 Office、Ops 都不过滤它，所以常驻 PM Office、PM Ops 和复用 pm 角色的工作项级 PM 都能看到并调用。
- `HOST_OPS_ROLE_TOOLS` 不变，host_ops 不获得此工具；produce / verify 角色的白名单不变（C-726 已含）。
- 工具本身、说明的数据结构、写入入口（人和主机 CLI，Agent Token 拒绝）和 Core Prompt 拼接逻辑都不改。

## 部署

默认角色包新增工具属于放宽，部署时系统升级入口不会静默写 pm 新版本，按既有流程生成差异核对事项，由人确认后常驻 PM 新会话生效；已在跑的会话和 Run 沿用原角色版本。

## 测试

- domain：`capability-guide.contract.test.ts` 新增常驻 PM 持有只读工具、host_ops 不持有、所有类型白名单里与能力说明相关的工具只有只读这一个。
- roles：`role-pack.test.ts` 新增 pm 默认包含此工具、host_ops 不含。
- mcp-server：`capability-guide.test.ts` 新增 PM Office、PM Ops 的 `tools/list` 与 `whoami` 出现此工具，读取结果与 `cardigan capability guide get` 所用的 `readCapabilityGuides` 一致；以 PM 身份写入被拒。
