# C-691 提示框边缘统一成头像提示框样式

所有者 11-24：所有提示框的边框颜色、阴影样式参考头像悬停卡片。状态与保存：无写入。

## 盘点（改前，基线 `f4832dcbd19376950be6fe7722cbac4b909a0d74`）

实测来自 `apps/web/test-support/c691-capture.mjs`（固定 Chrome Headless Shell 157.0.8103.15、DPR 1、合成数据）。

| 提示类浮层 | 组件 / 入口 | 改前样式来源 | 改前边缘（亮 / 暗） |
|---|---|---|---|
| 看板卡片标题、状态、编号、徽标提示；依赖图节点与连线提示；执行视图（角色版本、运行配置、会话维护）提示；设置说明 `SettingsHelp`；侧栏、视图切换、刷新、版本号、抽屉、优先级、时间线版本、飞书配置、快照页提示；可滚动状态详情 `DetailsTip` / `CardStatusTip` | `components/Tooltip.tsx` → `ui/tooltip.tsx`（`.ui-tooltip` + 旧 `.tooltip-content`），带箭头 | `--tooltip-bg/text/border` 令牌 + 旧样式阴影 | 亮 `#262626` 底、`#757575` 边、`rgba(0,0,0,.55) 0 4px 12px`；暗 `#222` 底、**`#777` 亮边**、`rgba(0,0,0,.75) 0 4px 12px` |
| 头像员工卡片（参照） | `EmployeeIdentity` → `ui/popover.tsx`（`.ui-popover` + 旧 `.employee-card`） | `.ui-popover`：`--surface` / `--control-border` / `--ui-shadow` | 亮 `#fff` 底、`#ddd` 边；暗 `#222` 底、`#363636` 边；均 `rgba(0,0,0,.2) 0 4px 16px`，圆角 6px |
| 容量浮层 | `Capacity` → `ui/popover.tsx`（`.ui-popover` + 旧 `.capacity-tooltip`） | 同上（旧样式另写的边框阴影被覆盖） | 同参照 |
| 依赖节点卡片浮层 | `layout/CardPeekLayout` → `ui/popover.tsx` | 同上 | 同参照 |
| 模板标记提示 | `TemplateMarker`（自行定位，`.template-marker-tip`） | `--tooltip-*` 令牌，自写圆角 | 深底、`#757575` / `#777` 边、**无阴影** |
| 附件图片缩略图预览 | `markdown.ts` 附件芯片（`.ui-attachment-ref-peek`） | 自写 `--surface` / `--border` + 自写阴影 | 阴影 `rgba(0,0,0,.16) 0 4px 12px` |
| 浏览器原生 `title` 提示（时间全称、提交号缩写、附件芯片等） | 原生属性 | 浏览器绘制 | 不可设样式，不在本卡范围 |

下拉菜单、选择框、诊断面板等点击打开的菜单面板不是提示，但同样由 `.ui-popover` / 菜单规则绘制，外观已与参照一致，未改。

## 做法

- `ui/theme.css` 新增 `--ui-tip-bg/text/border/radius/shadow`，分别引用 `--surface`、`--text`、`--border`、`--ui-panel-radius`、`--ui-shadow`，暗色主题经引用自动切换；删除 `--tooltip-*`。
- 唯一边缘规则 `.ui-tooltip, .ui-popover, .ui-tip`：Radix Tooltip / Popover 自动带上，模板标记提示和附件预览加 `ui-tip` 类；旧 `.tooltip-content`、`.capacity-tooltip`、`.employee-card`、`.template-marker-tip`、`.ui-attachment-ref-peek` 中的背景、边框、圆角、阴影删除。
- Tooltip 去掉箭头（参照没有箭头，低对比边框下无边箭头会断开）。Radix 原把箭头高 5px 计入偏移，现并入 `sideOffset`（6 + 5），提示框位置、尺寸逐个实测与改前相同。
- 亮色主题提示由深底浅字改为与头像卡片相同的白底深字（验收标准要求背景色一致），`ui-guidelines.md` 的 Tooltip 行同步。
