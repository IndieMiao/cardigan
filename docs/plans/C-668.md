# C-668 看板依赖连线改用平滑曲线（贝塞尔）

所有者要求（附件 board-dag-curve.png）：C-659 的悬停依赖连线是正交折线，沿列边和看板顶部绕行，看不出连的是哪两张卡。改成从一张卡直接连到另一张卡的三次贝塞尔曲线。状态与保存：无写入。

## 设计

| 项目 | 做法 |
|---|---|
| 曲线 | 每条线是一段三次贝塞尔 `M…C…`，没有直线段和直角。两端的控制柄水平、朝卡片外，所以曲线从边缘水平离开、水平进入，箭头（6px 同色小三角）始终指向卡片。 |
| 端点 | 不同列：两张卡相对的侧边（左边卡的右边缘、右边卡的左边缘），控制柄长为两端水平距离的一半、至少 24px。同列：两端在同一侧，柄长 16px，向外最多鼓出 15px，留在 16px 列间距内。 |
| 同列的一侧 | 取本卡跨列连线较少的一侧（相同取右侧）；那一侧鼓出会超出看板可视区而另一侧不会时改用另一侧。 |
| 起点错开 | 本卡同一侧的多条线按另一端的高度从上到下排，间隔 6px、以本卡（可见部分）中点居中；卡片露出太短时压缩间隔，保持距上下角 12px。另一端取其卡片（或折叠条计数处）的中点。 |
| 层级 | 连线层从看板之前移到之后：曲线可以从无关卡片上方经过而不被截断（C-659 设计验收 V-3178 指出画在卡片下面会被无关卡片截断）。线 1px、颜色为卡片悬停边框 `--ui-border-hover`（亮 `#bcbcbc` / 暗 `#505050`），不透明度 1，不接收指针，悬停和点击卡片不受影响。合成夹具中没有曲线压到卡片标题文字。 |
| 沿用 C-659 | 显示时机（悬停或键盘聚焦，触摸不触发）、关联卡高亮、不可见关联卡的处理（折叠列指向折叠条，滚出视口、筛掉、未加载不画）、滚动和尺寸变化跟随、离开清理，均不变。 |

## 已知取舍

- 相邻两列且上下相距较远的两张卡，水平距离只有列间距，曲线大部分落在间距里，接近竖直的平滑 S 形；同一间距里可能还有本卡的同列连线，靠两端位置、箭头和关联卡高亮区分。

- `src/useBoardDependencies.ts`：收集可见关联端后交给 `hubPaths`。
- `components/Board.tsx`：`BoardDependencies` 移到看板 `section` 之后。
