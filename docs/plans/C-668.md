# C-668 看板依赖连线改用平滑曲线（贝塞尔）

所有者要求（附件 board-dag-curve.png）：C-659 的悬停依赖连线是正交折线，沿列边和看板顶部绕行，看不出连的是哪两张卡。改成从一张卡直接连到另一张卡的三次贝塞尔曲线。状态与保存：无写入。

## 设计

| 项目 | 做法 |
|---|---|
| 曲线 | 每条线是一段三次贝塞尔 `M…C…`，没有直线段和直角。两端的控制柄水平、朝卡片外，所以曲线从边缘水平离开、水平进入，箭头（6px 同色小三角）始终指向卡片。 |
| 端点 | 不同列：两张卡相对的侧边（左边卡的右边缘、右边卡的左边缘）。同列：两端在同一侧。 |
| 控制柄（设计验收 V-3201 后改） | 柄长同时随纵向距离增长，避免相邻列和同列的线缩在列间距里竖着走。跨列：取“水平距离的一半”和“纵向距离的一半（上限 200px）”中较大者，至少 24px；相邻列上下相距远时成为 S 形，向两侧各摆出约柄长的三分之一，从卡片上方经过。同列：纵向距离的 0.35，限 24–180px，向外弧出约柄长的四分之三（最远约 140px），越过相邻列的卡片。控制点限制在看板可视区内，曲线（在控制点凸包内）不会超出看板、不产生横向溢出。 |
| 同列的一侧 | 取本卡跨列连线较少的一侧（相同取右侧）；那一侧弧不下而另一侧弧得下时改用另一侧；两侧都弧不下时取空间较大的一侧。 |
| 起点错开 | 本卡同一侧的多条线按另一端的高度从上到下排，间隔 6px、以本卡（可见部分）中点居中；卡片露出太短时压缩间隔，保持距上下角 12px。另一端取其卡片（或折叠条计数处）的中点。 |
| 层级 | 连线层从看板之前移到之后：曲线可以从无关卡片上方经过而不被截断（C-659 设计验收 V-3178 指出画在卡片下面会被无关卡片截断）。线 1px、颜色为卡片悬停边框 `--ui-border-hover`（亮 `#bcbcbc` / 暗 `#505050`），不透明度 1，不接收指针，悬停和点击卡片不受影响。 |
| 不挡文字 | 连线层按主题混合：亮色 `darken`、暗色 `lighten`（主题变量 `--ui-faint-line-blend`）。线色介于背景和文字之间，所以经过背景时显示原色，经过文字时文字像素保持不变。合成夹具折叠列场景中 C-51→C-23 经过 C-41 标题第一行：该行改变 32/29 像素（亮/暗），文字像素 927/1153 个中改变 0 个。 |
| 沿用 C-659 | 显示时机（悬停或键盘聚焦，触摸不触发）、关联卡高亮、不可见关联卡的处理（折叠列指向折叠条，滚出视口、筛掉、未加载不画）、滚动和尺寸变化跟随、离开清理，均不变。 |

## 可验证条件（V-3201）

证据脚本对每条线沿长度每 2px 取点，断言：

- 落在列间距内的最长连续长度不超过 80px（只允许斜着穿过；改前 265–510px）。实测 1440 为 20–60px；390 下看板右缘限制了摆幅，C-23→C-32 为 66px。
- 任意两条线在离开两端 24px 以外、彼此相距 6px 以内的最长连续长度不超过 40px（不并行）。

## 已知取舍

- 曲线会经过更多无关卡片（在卡片上方，靠混合保持文字像素不变）；线与线之间可能交叉，但不再并行。
- 窄屏（390）只有一列多可见，同列弧线和相邻列 S 形的摆幅受看板边缘限制。
