# C-590：APK 允许“-”开头的路径段

1. AAPT2 缩短资源路径后会产生 `res/-8.xml` 这类成员名。归档检查仅对 Android 放宽：路径段可以以“-”开头，与 C-582 对点开头的处理一致；iOS 解包仍拒绝点和“-”开头的路径段。
2. 其余规则不变：字符集、空段与绝对路径、`.`/`..` 及结尾的点和空格、大小写别名、文件与目录冲突、非常规文件、成员级 ZIP64、残留签名、大小与数量上限。
3. 成员名不进入任何工具的命令行：`platforms.android` 只把签名端私有目录中的输入、输出绝对路径交给 `aapt2`、`keytool`、`apksigner`；iOS 只把签名端解包目录下的绝对路径交给 `codesign`，且不放宽。
4. 测试用卡片给出的 4 个被拒成员名构造合成 APK，走完签名、验签与对账夹具；另测 iOS 不放宽、“-”开头名的非法边界和 ZIP64 成员。合并部署后由管理员按 README 换版签名端，再对真实候选重新登记、批准、送签。
