# C-555：外部提醒只发启用后的新事项

1. 在配置生效和应用绑定事务记录追加事件水位；同配置重启复用水位，停用再开或目标变化重新划线。在水位前的待发、失败记录标为跳过并审计，不操作 Workbench 事项。
2. 在发送领取事务按渠道（跨项目、跨进程）预留滚动 60 秒额度。默认最多 10 次尝试，重试、免打扰汇总及限速汇总均占一次。超额普通事项留在发件箱，共用一条只有数量和 Workbench 入口的汇总；免打扰与重试保留原有分组。
3. 用模拟渠道与临时 SQLite 验证历史 700 条知会、200 条待办、重启/重开/换绑、存量作废与跨项目突发。不触碰实际配置或外发；上线观察由卡片负责人安排。
