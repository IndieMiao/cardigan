# C-659 看板：悬停卡片时显示依赖连线

所有者要求：鼠标悬停（以及键盘聚焦）看板上的卡片时，显示它和前置卡、后续卡之间的依赖连线；默认不显示，线条要非常弱。状态与保存：无写入。

## 设计

| 项目 | 做法 |
|---|---|
| 触发 | 鼠标（含触控笔）悬停在卡片上，或键盘焦点落在卡片内的链接/按钮上。移到卡片间空隙、离开看板或失焦即消失。触摸点按不触发（点按本来就会打开卡片）。 |
| 数据 | 只用看板列表已有的 `dependency.predecessors` / `successors`，不新增接口。悬停前不测量、不计算、不渲染 SVG，首屏 DOM 与像素和改前一致（44 张基准图逐字节相同）。 |
| 线条 | 1px（`--ui-stroke`），颜色是卡片悬停边框的 `--ui-border-hover`（亮 `#bcbcbc` / 暗 `#505050`）。方向用末端 6px 的同色小三角表示，与卡片详情依赖图的弱化边同一写法。 |
| 走线（设计验收 V-3178 后改） | 正交折线、4px 圆角，**不经过任何卡片**：每条线从前一张卡（`from`）的右边缘出、进后一张卡（`to`）的左边缘（前置 → 本卡 → 后续，始终从左往右读）。竖段只走列与列之间的 16px 间距；相邻两列直接在中间间距里折一次；跨两列以上、同列或往左连时，先沿出口间距爬到看板顶部、各列标题上方的 10px 留白带，横穿后在目标列左侧间距落下。这样线的可见部分是连续的，两端只落在本卡和真正的关联卡（或折叠条）上，不会看起来停在无关卡片的边上。 |
| 分轨 | 间距内以中线为准：本卡发出的线出口在中线左 2px、入口在右 2px；指向本卡的线出口左 5px、入口右 5px；顶部带内发出的线在上（距看板顶 3px）、指向本卡的在下（6px）。方向相反的线不共用一段；同一张卡发出的多条线共用出口竖段，到各自目标高度再分叉。 |
| 层级 | SVG 放在看板滚动区之前、绝对定位且不接收指针；卡片画在线上方（走线本就不进卡片区）。看板边缘处间距在视口外时，竖段最多伸到看板外半个间距（8px，落在页面留白里），并始终在箭头前保留 2px 横段，箭头总是指向卡片。 |
| 关联卡高亮 | 线另一端的卡片边框改为同一 `--ui-border-hover`（与悬停卡片相同强度）。 |

## 关联卡不可见时

原则：线只画到屏幕上真实存在的目标，不出现指向空白处的断线。

| 情况 | 表示 |
|---|---|
| 所在列已折叠 | 画到该列折叠条上、与列计数同高处（折叠条代表这一列）。关联卡本身处于“已暂停”时同样指向折叠条，但折叠条上的计数不含暂停卡（沿用看板既有计数口径）。 |
| 在列内滚出视口，或横向平移到看板可视区之外 | 不画。卡片露出不足 8px 也视为不可见；部分露出时端点取露出部分的中点。 |
| 被筛选掉、尚未加载（分页），或在收起的“已暂停”区里 | 不画（看板上没有这张卡）。 |
| 悬停的卡自己被折叠/筛掉/刷新移走 | 立即清除全部连线和高亮。 |

## 跟随与清理

- 看板横向滚动（含拖拽平移、Shift+滚轮）和每列各自的纵向滚动：捕获阶段监听 scroll，下一帧按新位置重画；指针停留不动而滚动后落到另一张卡时，浏览器重新派发悬停，连线切换到那张卡。
- 窗口或看板尺寸变化（ResizeObserver）、看板 DOM 变化（刷新、折叠/展开列、加载更多；MutationObserver，仅在有活动卡时监听）后重画。
- 悬停状态放在独立的 `BoardDependencies` 子组件里（`memo`），指针在卡片间移动只重渲染连线层，不重渲染整块看板（代码审核 V-3177 建议）。
- 离开、失焦或卸载时移除所有 `data-dependency-related` 标记，不残留。

## 实现

- `src/board-dependency-lines.ts`：纯几何（可见区域求交、正交走线与圆角）。
- `src/useBoardDependencies.ts`：在看板根节点上用事件委托跟踪悬停/聚焦，只在有活动卡时测量。
- `components/BoardDependencies.tsx`：持有悬停状态的连线层（memo）。
- `components/layout/BoardDependencyLayout.tsx`（+ `.module.css`）：SVG 与箭头样式，只用 token。
- `Board.tsx`：在看板前渲染 `BoardDependencies`；列加 `data-status`。`BoardCard.tsx`：卡片加 `data-card-id`。`BoardCardLayout.module.css`：关联卡边框。
- 证据脚本：`test-support/c659-capture.mjs` + `c659-fixture.tsx`（16 张合成卡、7 条依赖，其中 C-99 不在看板上）。脚本沿每条线每 2px 取点，断言不落在两端以外的任何卡片内。
