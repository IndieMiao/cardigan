# C-498：新任务按需恢复 Godot 导入产物

C-498#7 的外置卷单次基线：独立 base clone 33.45 秒（不是每任务成本）；新 worktree 检出 10,070 个跟踪文件 / 921,451,204 字节，用时 6.02 秒。Godot 首导 73.69 秒，`.godot` 占 621,720 KiB；原地二次导入 11.01 秒。新任务基线是 **79.71 秒**，不是二次导入的时间。外置盘累计写字节未测，不能以目录占用代替。采样账号不是最终专用 worker 账号。

1. **只优化导入**：保留现有共享 Git 对象库和全量检出；不裁资源、不复用工作区、不挂载或硬链接另一任务的 `.godot`。提供可选的 macOS 项目导入命令，仅由目标项目的私有任务流程在首次需要 Godot 时调用。不改派发、Git helper 或 Cardigan 自身任务；不在检出时执行项目代码。
2. **种子按基线制作**：从同机、同项目、相同导入工具链与设置的干净全新检出，离线冷导入，只打包 `.godot/imported` 的常规产物（不含编辑器状态、插件、SDK、原工作区未跟踪文件）。由可信运维核对日志和项目资源后发布只读包及独立 SHA-256，放在项目专用、Assignment 不可改写的工作区外位置；不从任务回写或自动提拔种子。变更导入器、外部工具或设置即撤下种子重新预热。
3. **恢复和回退**：校验归档摘要、格式、Git 完整 SHA、Godot 完整版本和架构；逐文件复制进任务独有的新目录。始终让 Godot 实际执行导入，重新生成其余索引。包缺失、不匹配或损坏则清除本次恢复的部分产物，走一次冷导入；命中后导入退出失败也从空缓存重试一次。不覆盖已有缓存或清理已有工作区。冷导入失败返回失败。
4. **不接设备**：预热、命中、回退统一禁止 Godot 及子进程联网和执行 adb，另将 adb 客户端指向不可用的本地 socket；不依赖编辑器恰好没探测、默认端口没监听，或某一 Godot 版本会遵守 adb 环境变量。离线限制不可用即停止；导出或设备测试另走 C-497 的归属，不继承到纯导入。
5. **验证**：合成项目测试每次真的进入导入入口、独立副本、坏包和引擎失败回退、已有工作区拒绝、不启用时检出不变。现场另用同提交、同盘、同引擎的全新 worktree 做配对测量，报告检出到首轮成功导入总时间（含校验/复制）、一次性预热成本、资源正确性与离线隔离；不拿合成耗时替代。

## 使用与配对复测

纯导入入口是 `deploy/godot-import.py`（Python 3 标准库）。从固定的工具版本安装到项目检出以外；不赋予特权。种子针对**完整提交、具体 Godot 构建、同机器同项目**，生产包和摘要由工作区以外的可信方提供；工具不是发布服务。未配置种子的项目照常运行，若目标项目只需禁用设备访问也可只用冷导入命令。不是已打开编辑器的通用增量命令。

以下变量为占位符：`HELPER`、`GODOT`、`SNAPSHOT` 都是绝对路径。沿用 #3 的独立 base clone、目标提交、空间和空闲时段。不要在原工作区执行；每次在**不同的、未经编辑的独占可写 worktree 根**执行。不要用管理员身份运行 Godot。

```sh
# 在预热用的新树内。SNAPSHOT 必须是树外、尚不存在的暂存文件。
python3 "$HELPER" seed --godot "$GODOT" --snapshot "$SNAPSHOT"
# 记录预热/打包总时间。核对导入日志（退出 0 不足以证明资源齐备）、
# 所需资源和包摘要后，再由运维向本项目提供只读包和固定 DIGEST。

# 在无种子的新树内（对照组）
python3 "$HELPER" import --godot "$GODOT"
# 在同 SHA 另一棵新树内（命中组）：包含 SHA-256 校验、复制、实际导入。
python3 "$HELPER" import --godot "$GODOT" --snapshot "$SNAPSHOT" --sha256 "$DIGEST"
```

交替做至少两对，对每个新树从 `git worktree add` 前计时到上述命令退出，分别记录检出、导入入口、合计、`import=cold/restored`、导入错误和关键资源可用性。冷组/命中组不改变输入或使用不同 SDK 配置；比较导入产物清单及实际加载，不用 grep 计数当作功能等价证明。无下降、离线限制不可用或缺外部导入器则不启用。磁盘累计写字节按 #3 单独测，否则保留未测。纯导入使用 macOS 沙箱拒绝网络、拦截 adb 可执行文件并屏蔽 adb 客户端连接；现场用受控的非设备测试端点验证内核拒绝，不探测 5037，不要求启停 adb。二进制、路径、项目映射、端口和凭据不进仓库。
