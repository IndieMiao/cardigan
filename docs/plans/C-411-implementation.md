# C-411 模板标记实现

依据 Q-804 用户选择 B、D-1483（da52535ca02f67cd2d8548cc5b88bb6cbeb161b6）、V-1831 及 C-411#96。基于 cbd0c094d69499a4e077c4aa1b80226862546baa 实施，保留 C-408 详情结构和 C-410 帮助图例。

1. 现有只读列表响应增加卡片绑定版本的模板名称、编号、版本、内置身份；沿用已有模板解析，不逐卡获取详情，不改模板或流程。
2. 共用模板图形和名称提示。只有元数据确认的内置 dev@2 在看板、列表省略；历史、自定义、未知均显示。未知不猜身份，缺版本明确提示未记录。
3. 看板右上角、列表行尾（窄屏编号行右侧）、详情页头右侧放置 16px 图标、24px 浅底和 44px 命中区。鼠标、键盘、点按均可读，Escape/失焦/外部点击关闭；可访问名称提供完整信息，视觉提示不重复读屏。不在链接内嵌按钮。
4. 详情移除重复模板文字，保留标记完成等业务入口。帮助页复用图形映射并说明默认省略、历史版本和自定义回退。
5. 定向测试覆盖元数据解析及接口、默认省略边界、交互和开卡、三处与图例；运行 web/server 增量构建、lint、deps。只运行相关测试，本地不跑全量或 e2e。合成夹具覆盖所有类型、缺失和长名称，采集 1440×900 / 390×844 亮暗前后截图及几何/对比度/键盘测量，最终绑定实现提交。可信预检通过后交 W-1415、W-1418。

真实设备、真实读屏和非 Chromium 浏览器不以模拟结果冒称已验证。设计附件的旧测量不作为实现证据。

实际边界：列表窄屏以编号和标记、标题、可选列分行，保留显示配置与状态分组；模板标记沿当前共享主题变量，C-392 合并后由后合并方对齐。图例新增第 12 个标注，旧标注编号不变。新接口字段仅返回四项展示元数据。已有领域规则拒绝引用不存在的模板定义；本卡不改变该规则，未知回退用于新的模板类型及前端元数据缺失，不把损坏的存储记录当作正常卡片。
