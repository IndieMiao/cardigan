# C-407：界面说明小字规则

## 目标与范围

按卡片原文在 AGENTS.md 的「代码规则」下新增「界面」小节，其它章节保持原样。在默认角色包的 coder、ui_ux_designer、design_director、reviewer 中复用同一规则；设计验收和代码审核把新增的、未被要求的说明小字列为必须修改的问题。

本卡只补规则，不清理现有界面文案；现有小字由 C-392 处理，不修改开发方案正文。

## 交付与升级

修改默认角色包正文并更新受影响的启动提示词快照。沿用 Flow Lite B9 的默认角色包升级流程：审核、合并后由部署流程自动升级并知会，手改冲突沿用现有处理；不修改升级机制、工具权限或角色版本管理。

## 验证

先用 `pnpm exec tsc -b packages/roles` 构建测试依赖，再运行 `pnpm lint`、`pnpm exec vitest run packages/roles -u --maxWorkers=1`、`pnpm check:deps`。新 worktree 缺包入口时，用 `pnpm exec tsc -b packages/host packages/router` 补齐依赖检查需要的构建产物。逐条核对快照差异仅为本次规则增补；本地不运行全仓测试或端到端测试。提交后请求远程预检，同一完整提交通过后交付。
