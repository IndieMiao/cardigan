# C-579：刷新控制主机的只读镜像

- 每轮项目对账从已登记项目出发，独立于本机 Assignment，刷新已有基础镜像；缺镜像不创建。与工作区准备共用项目锁，单个项目刷新失败单独报告，下轮重试。
- 只从本项目的私有中心取 `refs/heads/*`，更新 `refs/remotes/origin/*`，清理中心已删除分支的跟踪引用，保留 `origin/HEAD`。不检出、不合并，不同步标签、候选、交付或本地分支。
- 同账号模式用定向 fetch；隔离账号不能读取 0700 的中心仓库，复用主机发起、Agent 账号接收的增量传输实现同样的刷新。不得在 Agent 仓库以主机身份运行 Git、修改属主权限或走远程 worker。
- 用真实临时仓库模拟远程更新 farm-dev、主机新建 integration/dynamicfarm，核对一个周期后的引用、脏工作区、本地分支和权限，以及缺失/错误镜像的隔离。
