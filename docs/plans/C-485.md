# C-485：必改项影响程度与带条件通过

- 新提交的每条必改项必须区分数据或权限错误、功能错误、仅提示或体验；旧审核原样读取，不回填或猜测影响程度。
- 默认仍在本卡返工。只有存在本次必改项、全部必改项都仅影响提示或体验时，审核员才可通过 `followup_card_id` 明确选择带条件通过。后续卡须在同一项目、不是本卡、尚未结束；与本卡复审 `recheck_required` 互斥。沿用原“不通过、待复审”的流程时，不把它当作完成验证的依据。
- 条件通过绑定原交付和版本，完成验收、合并门禁和独立复核投影按该审核事实判断；不扩大等价沿用资格。时间线及 Needs You 保留每项影响和承接卡号。
- 同步默认验证角色规则，沿用现有部署升级及知会机制。契约测试覆盖退回、后续卡校验、接受及门禁；验证相关包测试、域测试类型、增量构建、lint 和依赖方向。
