# C-408 卡片详情与抽屉整理

赵云实现，依据本卡目标及晴雯本卡增量设计 v2（attachment-4522）及 V-1826 的修正要求；本卡最新要求优先。

- 完整页和抽屉继续复用 CardDetailPage；抽屉使用外层唯一标题，完整页不再重复吸顶标题。
- 状态、真实等待人/下一步、更新时间、风险和模板组成单行元信息区，窄屏通过局部键盘/触控滚动完整阅读；没有值或只有占位时省略。
- 编辑、暂停同排，复制链接、敏感与取消/被取代进入公共菜单，沿用既有确认、请求及幂等语义。
- 概览收纳目标、验收与折叠背景；工作项、交付审核、时间线、附件按分区显示，切换保留草稿，深链接自动选择目标区。
- 预检无记录不渲染，有记录显示状态、被检提交、真实时间和可用日志入口；不把历史通过称为当前版本通过；日志页只保留完整被检提交、事件时间和检查明细。
- 沿用现有主题变量，不提前合入 C-392 未审核主题；不新增常驻说明小字，不修改开发方案正文。

验证：相关 Web 单测、受影响读取测试、增量构建、lint、依赖检查以及绑定提交的远程预检。用真实组件和同一份小规模合成夹具比较改前/改后：C-283 待整理情境、进行中、审核有预检，完整页/抽屉，1440/390，亮/暗；标明非生产数据，不将历史截图冒称当前界面。

实现规格：主操作与页签视觉32px、命中44px，水平内边距10px、字号14px；表单44px，控件/面板圆角8/10px。元信息13px且可聚焦、左右键80px及Home/End滚动。目标和验收默认展开，背景折叠；抽屉完整页面链接位于操作行，复制位于更多，初始焦点在关闭按钮。

预检日志复用已有同项目登录会话与安全文件读取器，新增只读入口接受系统登记的预检编号；来源、完整SHA和时间取系统事件，路径不从记录正文推导，保持二次会话校验、拒绝目录/符号链接与遍历。没有修改domain状态或卡片写入语义。

背景相关编号后显示可省略标题，并保留完整可访问名称及悬停标题；元信息向左/向右还有内容时分别以24px渐隐提示。
