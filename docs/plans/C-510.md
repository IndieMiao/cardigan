# C-510：Web worker 接入后端

复用 C-509 的人类登录、Origin、同机检查互斥和全局审计；不新增 MCP 工具。不改容量、能力上限或在线状态。目标机只接受已有接入引擎的非特权探测，管理员命令只作为文本返回。

- `POST /api/projects/:project/worker-wizards` 以 `{machine_id,label,os,arch,host,account,uid,gid,mcp_url,port?}` 创建预览。使用操作手册的路径约定、控制主机配置目录下预置的 `worker-key` 与 `worker-known-hosts`；不上传密钥。返回 `wizard`。SSH 端口默认 22，`account` 为专用 `cg_` 账号。
- `GET /worker-wizards/:id`（同一项目前缀）读取状态，包括 `steps`、耗时、原因、修复提示、`commands`。`POST .../:id/cancel {}` 作废；`confirm {preview_id}` 只写该绑定的接入 YAML；不改正式派发配置。确认绑定当前文件字节、当前人和项目；同绑定新预览替代旧预览。保留原始字节的 0600 备份，原子替换。文件或项目/机器身份冲突不猜测覆盖。
- `POST .../:id/run {}` 启动检查或续跑，返回 202，页面轮询 GET。登记仅新增离线绑定；每步进度在 Web 会话可见，同配置同会话的已通过步骤不重做，能力刷新也须通过。管理员在目标机按返回脚本及对应操作手册处理后可调用同一接口复查。
- 检查通过后 `POST .../:id/launch-preview {}` 预览 `runtime-workers.yaml` 中该绑定的单项合入；`POST .../:id/enable {preview_id,allow_remote_launch:true}` 再验证文件、检查和登记后才开启。可以不执行最后两步。其他绑定、容量和在线状态不变。
- 预览 15 分钟有效；向导会话 24 小时有效，限当前 Web 进程、当前所有者。同机检查结果与接入 journal 仍持久保存。进程重启须新预览以重新授权。仅用隔离夹具验证配置、权限、失败续跑和两种目标系统，不创建真实账号或打开生产派发。
