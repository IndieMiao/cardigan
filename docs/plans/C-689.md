# C-689 看板依赖连线和流动光点按参考图加强

所有者 11-24：C-659 / C-668 / C-673 的悬停依赖连线和光点太淡，要求线更明显、光点更亮，颜色对齐参考图（C-673 的 attachment-9282 board-dag-flow.png）。状态与保存：无写入。C-673 中“线和光点都保持克制、用卡片高亮边框色”的做法以本卡为准调整。

## 设计

| 项目 | 做法 |
|---|---|
| 颜色变量 | `ui/theme.css` 新增 `--ui-dependency-line` / `--ui-dependency-dot` / `--ui-dependency-glow`，亮暗各一套：亮 `#3d9caf` / `#0c8aa3` / `#29c4dd`，暗 `#79b8c2` / `#c8f9ff` / `#3fdcf3`。连线样式只引用变量，不写色值。 |
| 连线 | 1.5px（`1.5 × --ui-stroke`），取 `--ui-dependency-line`；线下另画一条同形 4px、不透明度 0.25 的同色光晕（轻微发光）；箭头同色、尺寸不变（6px）。线在卡片底色上的对比度亮约 3.2:1、暗约 7:1。 |
| 光点 | 核心 4px 实心圆点取 `--ui-dependency-dot`（暗色接近参考图的亮白青，亮色为更深更饱和的青），下面三圈 `--ui-dependency-glow` 光晕：18px / 0.1、12px / 0.2、8px / 0.5，叠起来由内向外渐淡。光晕圈与光点用同一虚线属性，由同一帧循环一起推进。数量（1–3 个、约 240px 一个）、速度（64px/s）、方向（前置卡 → 箭头）沿用 C-673。 |
| 文字可读 | 连线层继续按主题混合（亮 darken / 暗 lighten）。线和线下光晕同色，比标题文字笔画浅（亮）/ 暗（暗），经过文字时文字像素不变；光点比文字更亮（参考图如此），经过文字时短暂提亮，只记录不断言。 |
| 播放与减少动态效果 | 不变：只在悬停或键盘聚焦显示连线时挂载并播放；`prefers-reduced-motion: reduce` 时不渲染光点和光晕圈、不启动循环，保留静态线、线下光晕和箭头。 |
| 性能 | 每帧写每条线 4 条路径（光点 + 3 圈）的虚线偏移，不读布局；不用 SVG 滤镜（模糊滤镜每帧重算代价高），光晕用叠加的宽圆端点实现。 |

## 实现

- `components/ui/theme.css`：三个颜色变量。
- `components/layout/BoardDependencyLayout.tsx` / `.module.css`：线下光晕 `data-edge-glow`、光晕圈 `data-flow-glow` + `data-ring`、新样式。
- `useBoardDependencyFlow.ts`：帧循环同时推进 `[data-flow]` 与 `[data-flow-glow]`。
- 证据脚本 `test-support/c689-capture.mjs`（由 C-673 脚本改写，见 test-support/README）。

## 已知取舍
