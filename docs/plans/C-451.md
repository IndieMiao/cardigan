# C-451 · 向导核对已应用的 worker 配置

沿用 C-429 的远程派发授权和 C-445 的重新确认流程。完整校验私有运行配置后，比对同一项目绑定时仅忽略由人管理的 `allow_remote_launch`；机器身份、其余项目字段和草案完整性仍按原规则核对。不改配置写入、启动授权或默认值。

用临时配置覆盖开关缺省、开启和关闭时的 `check`、`resume` 和确认新摘要；验证运行配置不被改写、开关不被带入新草案，真实绑定冲突仍被拒绝。合并部署后由张良分别在 Linux 共用执行机和 Mac 上保留当前开关，各跑一次 `worker check`。

审核修复（V-2044）：仅在读取已应用配置时排除开关。向导保存的草案仍完整比对；若草案被加上开关，普通 `resume` 和 `check` 必须在调用登记或改写日志前报冲突，草案保持原样。
