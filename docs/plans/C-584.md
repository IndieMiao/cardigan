# C-584 · PM Office 向所有者发送飞书私聊

1. 在项目偏好增加仅人可写、默认关闭的开关。只给托管常驻 PM Office 发放和展示工具；执行时按 Token 再验身份、同项目卡片、敏感标志和飞书所有者绑定。
2. 单独持久化纯文字消息，不创待办、不改 Needs You 通知投影。入队和发出分别执行每项目滚动一小时六条的上限；后台复用现有免打扰、私聊绑定代次、渠道分钟预算。发送前再次核对开关和卡片；结果不确定不重发。
3. 卡片时间线记录摘要、正文 SHA-256 和受理／投递结果，不保存收件地址；投递结束清除队列正文。PM 默认角色包按既有部署升级机制发布，不修改在岗身份或项目配置。
4. 契约测试覆盖 Office、Ops、工作项和外接身份；模拟私聊通道贯穿 MCP 调用、排队和投递，按卡片给出的 attachment-64 栏目构造虚构版本说明。不发送真实消息。
