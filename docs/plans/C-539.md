# C-539 · Worker 会话只读取证

1. 新增常驻主机运维专用工具。只收机器、指派、可选运行编号；在同一事务核对项目、归属及最近取证事件，先记编号和结果再发起查询。限流按项目共享，不因重启或多服务进程失效。
2. 使用服务端登记的项目 worker 连接（含回环连接），拒绝未绑定 worker 的主机进程直读；目标指纹变化不交出旧结果。只观察已有 hc socket，不调用可启动 core 的 CLI。屏幕只保留可识别的运行状态，命令行只保留可识别的程序和安全参数；未知内容不原样传出。文件读取不跟随符号链接，只提取标记、摘要或日志事件类型和时间。
3. 更新默认角色使用规则，以合成的本机和远端配置、临时目录和协议夹具验证权限、归属、限流、边界及失败。真实机器探查不属于开发自测。

配置与结果：项目共享取证间隔默认 10 秒，可由服务端 `CARDIGAN_WORKER_INSPECTION_INTERVAL_MS` 设置正整数毫秒数。每次最多 4 个终端，每个 12 行屏幕、8 条日志事件；返回 `null` 表示未能观察，空数组表示该查询没有匹配项。没有隔离账号的开发用 local 模式不回退到控制器账户。

归属与不完整证据：省略 Run 时先找唯一占用者；空闲指派的证据不标成某个已完成或排队 Run。复用会话时分别返回被查询的 Run 和现场的启动 Run；未能证明关联只返回可独立确认的机器信息或发布标记。查询结束前再核对绑定。每次读取前重新验证账号独占和不可由工作账号改写的项目声明，缺少证明即拒绝，不替旧配置认领账号。

平台与采样：本机恢复用的 UUID 只作终端标签，本机日志读指派目录；远程发布代次才定位版本化目录。Linux 走工作账号的私有运行目录，macOS 走现有会话状态目录。进程须在采样前后保持出生身份和终端归属；遍历或尾窗不完整且不足以确认最后八条时，日志返回未知而非无事件。
