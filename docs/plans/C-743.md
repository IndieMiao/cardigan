# C-743 · 存储保留策略：自动部署旧版本、数据库备份、已释放指派的运行目录

所有者 11-25 批准清理旧发布版本、7 天外数据库备份和已释放指派的 runs。本卡把 C-520 的“预览 + 人工批准”改为按策略自动回收，C-520 的批准清单流程（`approval`、`retention-preview-N.json`、只删空壳）随之取消。

## 部署目录（更新监督器）

- 每次部署成功并就绪后（`maintainDisk` 原有门槛不变：回滚、未就绪、运行版本不一致、服务不在都不做）按策略清理一轮，同一次部署只做一轮。每个监督器节拍只处理一项，不占部署节拍。
- 发布目录：按修改时间保留最新 `release_keep` 个（默认 10）；`state.json` 的 current / running / previous、初始发布和监督器自身所在发布永远保留，删除前按当时的引用再核一次。只认命名合规、属主为主机账号、权限 0700 且与部署目录同一文件系统的目录；删除不跟随符号链接、不跨挂载点，只读子目录先补属主写权限。
- 数据库自动快照：保留 `backup_days` 天内的（默认 7）且至少保留最新 `backup_min` 份（默认 3），恢复引用的那份永远保留。只看部署目录下直接生成的 `database-<uuid>.bak`，不进入 `backups/`、`backup-manual/`。
- 一轮结束写 `host_retention_round`（项目流）：删了几个发布、几份备份，各腾出多少字节，失败项，名称（最多 100 个）和白话 `notice`。

配置（私有 `self-deploy.yaml`，均可省略）：

```yaml
retention:
  release_keep: 10
  backup_days: 7
  backup_min: 3
  mode: auto   # preview：只记录本轮会删什么，不删除
```

C-520 的旧键（`revision`、`releases`、`snapshots`、`daily_days`、`released_days`、`approval`）仍可解析但不再生效，主机现有文件不必改。

## 运行目录（服务端循环，本机和远程 worker）

- 新循环 `run_dir_retention`（默认 15 分钟一轮，逐台机器）。机器须在线或降级；离线的不判断。
- 可回收条件：指派已释放严格超过 K 天（默认 3）、终端退出已确认（`runtime_ref` 已清）、没有未结束的 Run、没有待处理的主机运维动作或远程 worker 失联记录、没有开放的人工待办点名其工作项，且所在卡没有被 PM 点名保护。活跃指派一律不碰。
- 删除在目标机器上执行：通过该机器的 Agent 账号 SSH 通道内联运行 `run-dir-retention.py`（与 `run-resources.py` 同样方式，不改已安装的 worker helper 协议）。脚本只接受主机给出的 `A-n` 名称、只在 `<根>/runs/<项目>/` 下操作，不跟随符号链接、不跨挂载点，不回传路径或错误细节；每次调用有时间预算（默认 60 秒），超时记为未完成，下轮继续。
- 控制主机本机的 Agent 机器上，运行目录叶子归主机账号（2770），Agent 账号先删自己的内容，主机账号再删剩余的主机文件和叶子本身。
- 每轮有进展就写 `host_run_dirs_reclaimed`（项目流，PM 读取项目流时可见）：机器、删了几个、腾出多少、未能删完的名称、白话 `notice`。没有进展的同一结果（连不上、删不动）只记一次。
- 配置：`CARDIGAN_RUN_DIR_RETENTION_DAYS`（默认 3）、`CARDIGAN_RUN_DIR_RETENTION=auto|preview|off`（默认 auto；preview 只统计可回收的目录和大小，即保留的人工预览方式）。

## PM 点名保护

`update_card` 新增 `keep_run_dirs: { reason } | null`：PM 或人给一张卡（包括已完成、已取消的卡）设置后，该卡所有已释放指派的运行目录不自动回收；传 null 解除。单独使用，不与其它字段混用；时间线记 `card_run_dirs_keep_set` / `card_run_dirs_keep_released`。

## 诊断

`host_ops_read_diagnostics` 的部署诊断新增 `retention`：最近 30 轮（部署目录和各机器运行目录），每轮的范围、机器、模式、删除个数、腾出字节和说明。

## 不在本卡

- 低空间提前触发：C-666 暂停中，本卡只做按时回收。
- 不回收活跃指派的任何目录；不动 `backups/`、`backup-manual/` 里的手动备份。
