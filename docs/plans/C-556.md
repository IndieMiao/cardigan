# C-556 等拍板时的门铃与本机恢复

- 在本机使用已绑定的只读证据；不能仅凭 core 不通推断程序退出。停止、再次排队前仍核对工作区、真实归属及未结束 Run。
- 将审核等待准入放进排队事务。暂停期间仅让本工作项的定向指令（含当前方案核对）唤醒审核员；保留等待状态、额度、正式提交门禁。恢复链保留触发通知，拍板解决时处理旧的空排队启动。
- 保留 shell 是已知终端策略：继续只读观察，不要求主机运维重复诊断；其他故障照旧。
- 隔离回归覆盖以上路径及拒绝分支。上线后由张良另行统计 24 小时内同类人工重启事项。

返工验证顺序：先在证据不全时实际巡检，再给原通知补齐证明，失败提醒与停止动作分别去重。旧版 loopback 的系统轮次恢复使用工作账号已有 socket 上的定点归属证据，发信号前在原有 pidfd 停止槽内重查。普通审核重启在受理和停止前检查暂停；已开始停止的只确认退出，若已暂停则不排新轮次。保留 shell 的归属连续复查失败时仍走原有告警门槛。

Flow 5 本机 SSH 启动不带终端代号（`launch_generation`）。恢复时，用原终端的首个已确认门铃和被系统结束轮次的门铃分别核对完整绑定，再到工作账号的 socket 核对创建终端的 Run 标签；不把复用终端的后续 Run 当作创建者。记录缺失、先后不明或标签冲突时不发停止信号。H-192 隔离回放从实际启动、派发和发铃开始，保留待处理通知，验证复用后只恢复一次。
