## 实现与缓存边界

列表、看板共用控件；刷新选择按项目和已验证登录会话的公开读取命名空间保存在浏览器。正文仅留在当前客户端实例内存，最多 32 个查询；退出、登录身份变化及鉴权失败清空，旧会话的迟到响应不能回填。筛选、排序、页码、每页数量和视图分别缓存。SSE 记录变化，只有定时、立即刷新或明确分页操作读取列表；抽屉详情沿用原刷新行为。

服务端默认缓存 5 秒，最多 64 个查询，每个查询保留当前和前一版本；可通过 WebServerOptions.cardsCache 注入调整，时长设为 0 可关闭复用以便诊断。HTTP 登录与项目校验先于缓存；当前版本涵盖项目、全局身份、其它项目的队列相关变化及门铃预留，回滚代次也参与版本。未变化时传空卡片增量，变化时传变化行和完整页内编号顺序，客户端据此删除离页卡片、更新排序。未知或淘汰的旧版本安全退回普通当前页读取。缓存不用于写授权。

角标只读领域派生所需的工作项、交付、审核、决定与人工事项，再用聚合 SQL 计数；不为计数读取事件、Run、附件、时间线或完整卡片展示状态。负责人、审核当前目标和固定模板版本仍由现有领域函数判断。物化派生表的编号显式转成文本，让 SQLite 使用自动覆盖索引，消除每卡、每泳道对整张 JSON 派生表的嵌套扫描。未增加数据库迁移。

交付及派发共享的命令集合读取按不可变源数组复用；草稿写入只使相应集合失效，保留重复键的最后值、原编号顺序与回滚隔离。仅实体变化时复用相同事件历史，避免重建全量事件索引。事务、Token 重查、审核隔离与派发顺序不变。新增固定阶段耗时，区分准备状态、Git 验证等待、事务/领域/持久化、提交固定引用，以及派发状态读取、领取、准备、激活、唤醒；不记录 SQL 参数、请求正文或凭据。

按 C-386#15 的补充要求，加载、刷新与失败重试提示位于卡片区域顶部的独立细状态栏，不占右上角按钮位置；后续统一通知区可以替换此局部组件。
