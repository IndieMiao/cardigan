# C-530：保留活会话，只收尾有私用凭据的任务

Q-1002 保留活会话和原门铃，不为升级强制换 CLI。每次从门铃取当前 Run 编号，不沿用上次编号。在新会话中用 `/usr/bin/python3 -IB -c "$CARDIGAN_RUN_COMMAND" R-n --private -- 命令 参数` 启动本任务的开发服务、浏览器或临时命令。临时文件写入该命令的 `$TMPDIR`。不要将跨任务共享的服务登记为私用。

## Q-1019：登记不是强停许可

- 每次登记创建一对无路径的私有套接字。监督者持有通知端（Vite 可在同一通道回报保留原因）；任务只收到自己的参与端 `CARDIGAN_PRIVATE_LIFETIME_FD`。不广播到 CLI、PID 名单、进程组或整个会话树。前台取消只作用于该次调用；普通的前台结束会把退出码交还调用方，不表示后台服务结束。
- 在可信的 Run 终态、该次前台取消或已绑定的 CLI 确认退出后，监督者发送 `cardigan-private-settled-v1\n`。进程应在自己的服务关闭接口中处理这条通知：停止接纳新工作，等现有使用者释放后退出。只有私用后代允许显式继承同一参与端，即使另建进程组也能收到。多个持有者用 `recv(..., MSG_PEEK)` 看完整记录而不消费；不能把 EOF、失败或超时解释成终态。
- 普通短命令无需适配。长驻工具需要有理解此通道的任务所有者或启动适配器。例如开发服务器用自己的关闭接口等待请求完成；浏览器由实际持有其私有控制连接的启动器关闭。**单独把任意未适配的程序放在 `--private` 后面不能证明它可强停**。没有安全的关闭接口、仍有外部使用者或不能确认收尾时，记为保留，不发 OS 信号。旁路进程一律不按亲缘关系处理，空闲进程也可能留下。
- 监督者分别审计已观察到的直接子进程退出且私有通道全关闭、通知后尚未释放、参与端已失联。没有主张枚举所有后代。参与端已失联时不能根据外部 PID 补发信号。两 Run 复用、同账号对照、前台取消、跨组持有者、登记服务仍在用及未登记服务仍在用分别验收。

### Vite 开发服务（Q-1029）

在已安装 Vite 的项目目录运行 `/usr/bin/python3 -IB -c "$CARDIGAN_RUN_COMMAND" R-n --private-vite 已分配端口`，只启动本次实例，不接管现有端口或浏览器。有端口分配表时必须匹配，不自动换端口。

- **接入过不等于用完了。** 客户端可以取回清单、断开 TCP，过一会儿再连接取资源。适配器在把首条连接交给 HTTP 处理前记下「已接入」，此后即使没有在途请求也不清除。收到收尾通知后保留原监听，让同一客户端能继续访问；不要求客户端登记或续租。一次探活也算接入，之后可能留下该实例。
- **从未接入的正例。** 目前只为锁定的 Vite 8.3.5、未加载项目 Vite 配置的实例证明这一点：以中间件模式启动，禁用额外的 WebSocket 和开发者工具，只由适配器持有一个回环 HTTP 监听。配置选择在创建时固定，不会因稍后出现配置文件而增加入口。首次接入与封闭入口由同一事件循环串行处理；只有全程可观察、尚未接入，且收到可信收尾通知时，才先关闭这个监听、再正常结束 Vite。不以启动登记、瞬时连接数或空闲时长代替独占证明。
- **观察不全就保留。** 有项目配置的 Vite 仍按配置启动；插件可能自己开端口，主监听从未被访问也不是独占证明。此类实例及未经验证的版本不自动关闭。适配器只在本次专用通道回报固定的保留原因；监督者按登记记「外部使用未确认释放」或「接入途径不可证」，回复缺失按原规则记未确认。回报不能授权停止或证明已释放，不传客户端身份、URL 或请求内容。

隔离用例使用真实 Vite 与签名控制端：先关闭短连接并确认保留审计，再由同一客户端重连按清单取资源；验证在途请求和插件独立入口也能继续服务。正例从就绪输出获取端口，不以探活污染使用记录；核对正常退出和端口可重新绑定。其它服务、浏览器仍须使用其原有权限内的关闭接口，不连接他人的实例。

## 谁能确认终态

- 控制端在自己的数据库中按需建立签名身份；只把公钥、查询地址及本次登记标识编入入口。状态查询发送限本次查询的消息认证码，不发送 Assignment Bearer、Token 哈希或私钥。请求绑定短时随机挑战、登记和 Run；答复由控制端签名，并绑定挑战、项目、机器和状态。收到答复后校验，过时、签名错误、控制端换钥或无法确认均不据此收尾。回环地址本身不代表控制端身份。不依赖代理，不跟随重定向。普通 MCP 授权不变；有效内部角色不必有 `whoami` 权限，查询不触发门铃、ACK 或其它工具。
- 远端直接从受信运行时参数执行管理员预装的 worker helper；它先核对主机所给摘要，再解析同一份启动描述字节。本机用运行时给定的摘要校验启动脚本，只执行已核对的字节。凭据文件按数据及预期字段读取，不把它当成可执行代码。每次执行专用入口都重新校验源码，执行内存中的同一份字节，而不是校验后再按路径打开。发布目录本身不是信任根。
- 监督者在建立会话监听前先让日志库关闭继承的连接，避免审计重连时占用监听句柄。监听失效不等于 CLI 已退出；直接子进程已退出但仍有跨组参与者保持连接，也不计作已释放。
- Linux 用 pidfd 绑定 CLI，取句柄后再次核对父关系；macOS 用进程退出事件并复核出生身份。状态读取通常每 15 秒一次；本机与控制端时钟需在请求窗口内（`CARDIGAN_RUN_RESOURCE_CLOCK_SKEW_SECONDS`，默认 120 秒），超出只会拒绝。预览可配置过期阈值，默认 24 小时；旧终态不当作新的收尾许可。

## Q-1011：不承诺释放磁盘

本机、cardigan-ci、mac-mini 保持现有账号、权限和存储。普通共享临时目录只记录保留原因，不遍历内容、递归删除、重命名或移交 C-520。存量只预览，每个目标每轮最多读取 1024 项目录元数据，截断标注 `partial`。不启用现场清理。Linux 隔离夹具实测与 macOS 退出事件模拟分开报告，不把 CI 通过写成 mac-mini 实机验证。

远端部署需要配套更新既有管理员预装的发布 helper；不将工作区文件当作受信替代品。未升级不降级为不验签或无摘要启动。本卡不安装现场 helper 或改变机器账号、权限。
