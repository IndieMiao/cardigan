# C-569：审核轮限暂停跟进

- PM 选择暂停时在同一事务绑定本卡当前 Assignment、下一步动作、一个或多个待确认 Assignment 和复查时刻（默认 30 分钟后）。暂停不释放正式返工或审核。人的直接拍板、已存旧暂停仍兼容。
- 复用 `post_comment.review_plan`：负责人提案，指定确认人逐一回复当前版本；换版清空旧确认。到齐仅通知当前拍板人（默认 PM，升级后为人），恢复仍走原轮限结案命令。拍板、指令和提醒均以结构化编号关联。
- 复用主机现有拍板巡检；到期提醒 Ops，发出后再过等长周期提醒 Office，每级只记一次。看板和卡片共用暂停阶段和下一步负责人的投影。
- 契约回放 Q-1107 双确认迟交证据表、Q-1108 确认后结案并实际返工；覆盖校验、旧版本回复、权限、到期与重启重试。更新内置 PM 规则，沿用部署升级流程，不改项目配置。
- 已排队但尚未派发的返工保留原编号，让同一暂停的讨论先单独派发；未结案时不得替换原交付。回放须经过实际收件、派发和开工路径，并验证无论讨论先结束还是 PM 先结案，均只派发一次原返工。
