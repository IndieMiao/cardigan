# C-490 监督器升级提醒

1. watch 从中心 Git 比较运行版本与 main 两棵树，而不是数提交。入口、部署文件族及共用运行包的边界集中定义；排除测试、文档和其它应用。依赖清单和锁文件比较相关运行依赖（含传递解析），不因为 Web 安装项变化而交人。
2. 每个已核实的 main 只检查一次。某个依赖文件未能核对，不影响其它文件已证实的相关变化。只有未知证据时保留原待办并重试，在项目动态按运行版本和 main 各组合记一次；不创建交人待办，不影响部署门禁。提醒写明相关文件或包以及私有部署 README 的操作章节，不执行升级。
3. 以系统请求事件和监督器 SHA 为依据，在事务中复用、补充或关闭待办；取消不记为完成，保留原因和项目事件。人工已处理的提醒不重发；旧误报不占用以后真正变更的提醒。
4. 用临时 Git 和 SQLite 验证无关合并、相关文件、依赖锁、轮询/重启和旧待办收尾；补系统专用命令的领域契约。无部署配置、数据库迁移或私有仓库改动。
