## 范围与步骤

1. 核对 C-338 最终交付 D-1235（`24ca88012a708803903e251cc91af14569a3d02f`）及附件 2780、2762。原种子 338、diagnostics 档的 329.3ms 是 `c233720f276b6f3d1ae91470716f5fa9fd557b28` 的历史结果，不能作为当前基线实测。
2. 复用 C-287/C-338 合成生成器，记录当前基线冷、暖、跨连接 revision 失效下的完整响应、阶段墙钟与 CPU、事件循环最大延迟和独立客户端轻请求 RTT。仅有界顺序业务请求，不连接生产或读取私有数据。
3. 消除每张卡片对全事件历史的预检排序，按不可变事件数组复用纯投影索引。跨卡审计在原写事务内只读取一次当前身份、偏好和工作项，逐卡重新检查访问范围后原子写入单个审计。
4. 新旧完整响应逐字段对照；补齐预检排序/身份/卡片隔离、新数组失效，以及敏感标记、撤销、配置改变、事务失败的契约。不引入快照结果缓存、TTL、超时或并发规则，不改变字段、角色和容量口径。
5. 运行 domain 契约与 test:types、Store 快照/事件/事务、MCP 快照/跨卡/服务端、server 直接装配/容量/响应回归，以及增量构建、lint、check:deps。全仓和 E2E 由同 SHA 远程预检负责。

实现说明与实测结果记录于本文件和交付附件。按当前 AGENTS.md 不修改开发方案正文；本卡无用户界面改动。合成数据不证明生产锁竞争或全部短停顿已消失。


## 已有工作与实现边界

已直接读取 C-386 最终 D-1451（`37a0fbe8abdf59d6294c08924a5c360aa972a2a8`）和 C-399 最终 D-1422（`fe056454d7df72197faf7a028c6a216aa0ad8534`）。前者覆盖共享命令集合与页面缓存，明确保留逐卡预检排序；后者覆盖 SQL 索引，明确保留约十秒的项目投影。本卡不重复这两部分，也不将 H-113 的生产 CPU 目标描述为已验证。

预检索引只由不可变事件数组标识，不以项目编号或身份字符串缓存整个响应；新事件数组重新派生，回滚继续使用原数组。仅可信系统预检参与排序，保留同序号稳定顺序、尝试编号最后值与返回顺序，返回新数组避免调用方改动索引。参考读取仍先按当前身份裁剪事件，卡片与角色权限每次照常校验。

审计仍在原同步写事务内取得最新 Token、Assignment、偏好和工作项，只是一次读取后供本事务各卡复用。各卡仍分别检查项目、敏感标记和完整／摘要权限；整组成功才写一条审计，持久化失败仍报错。这个读取器不跨事务、不跨请求保存。没有数据库迁移、生产配置、调度或用户界面改动。

Node 24.22.2，diagnostics 档／种子 338。全库 338 卡，其中主测项目 337 卡（313 张历史关闭卡、24 张执行卡）；55015 事件、1138 工作项、1141 Assignment、5556 Run、18075 时间线、920 附件、590 决定、158 交付、108 审核；40 个活跃非 external 会话。生成器与 C-338 相同，当前 schema 与额外恢复表按当前基线生成，不复制生产数据。

每版顺序执行冷读、两次暖读、一次外部连接更新卡标题并追加事件后的读；间隔一秒。每次快照开始后十毫秒，由独立客户端线程发送一次轻量身份查询，完整读取响应后计 RTT；不是同一事件循环里排队的假客户端。每次同时最多一个快照和一个轻请求，使用新 HTTP 连接。暖读表示行缓存与代码已暖，实际 MCP 活动与审计仍会递增 revision；另测两次不改变 revision 的领域查询。请求 JSON 98 字节，完整 MCP JSON 响应 681420 字节，改标题后 681418 字节；传输含文本与结构化结果两份表示，不含 HTTP 头。

阶段用墙钟及 process.cpuUsage 记录；装载包括事件流和命令状态缓存，投影为读事务总时间扣除装载，审计为写事务总时间。CPU 为进程累计时间，包含采样和客户端线程开销，不等于单核占用百分比。SQL 次数为 handler 内 all/get/run 次数，含 revision 与权限查询，不含入口鉴权／自动 ACK。事件循环使用十毫秒直方图与实际定时器间隔的较大值；原生直方图偶尔漏过同轮阻塞，原始两值均保留。下表单位毫秒，依次为基线→实现。
