# C-807：存储桶没开 CORS 时系统自己查出来，页面给出具体修法

背景：私有桶没有 CORS 规则时，主机直连 OSS 一切正常（不受 CORS 约束），异地存储健康显示可达；只有浏览器在共享文件页直传时被预检 403 拦下，页面只说“无法连接存储”。C-685 的合并后跟进第 1 条没有转成待办。

## 做法

| 位置 | 作用 |
|---|---|
| `packages/mcp-server/src/offsite/cors.ts` | `corsPreflight`：对桶发一个与浏览器相同的预检（`OPTIONS /shared/<固定 uuid>`，`Origin` + `Access-Control-Request-Method: PUT` + `Access-Control-Request-Headers: content-type,x-oss-forbid-overwrite`）。不带 Authorization、`x-oss-*` 头或签名查询，URL 没有查询串。结论：`ok`、`not_enabled`（403 且正文含 “CORS is not enabled”）、`not_allowed`（其它 403，或 200 但没放行该来源/PUT/两个头）、`unreachable`（网络、超时）、`error`（其它状态码）。正文最多读 4 KiB，只用来分类，不保存、不记日志、不返回。 |
| `apps/server/src/offsite-sync.ts` | 后台同步每轮在 OSS 配置就绪时按来源逐个预检：全部通过后 30 分钟复检一次，有拒绝或无结论时 2 分钟复检一次；来源列表或目标桶变化立即检查。结果写入 `status.json` 的 `cors`（来源、结论、状态码）。只有“有来源被拒”或“全部通过”算有结论，结论变化（及启动后第一次）时回调 `onCors`；不可达或异常状态既不开也不结待办。 |
| `apps/server/src/web/config.ts` `workbenchOrigins` | 检查的来源：配置的 `CARDIGAN_WEB_PUBLIC_ORIGINS`（含 Tailscale 地址）；没配时用监听端口的 `http://localhost:<port>`、`http://127.0.0.1:<port>`。 |
| `packages/mcp-server/src/offsite/offsite.ts` | `Offsite.cors()` 读同一目标的预检结果，有来源被拒时给出 `blocked: {reason, rule}`；`status()` 带上 `cors` 并加告警 `cors_blocked`。规则：来源为全部检查的来源，方法 `PUT、GET、HEAD`，允许头 `content-type、x-oss-forbid-overwrite`。 |
| `packages/domain/src/commands/storage-cors.ts` | `reconcileStorageCorsAction`（仅 system，权限 `record_storage_cors`）：有拒绝时开一条无卡片的交人待办（`category=account`、`triage=human`，说明写 OSS 控制台“数据安全 → 跨域设置”的具体步骤和规则），已开的同类待办只刷新步骤；全部通过时用 `cancellation.source=storage_rechecked` 自动结项。人手动关掉而桶仍拒绝时不再重开，直到中间有一次复检通过（记 `storage_cors_recovered`）。账号类待办系统不能“完成”，只能由复检通过时以系统复检原因结项。 |
| `apps/server/src/offsite-cors-notice.ts` | 把回调写进平台项目 `cardigan`（与部署提醒同一处）；该项目不存在时只在健康页和共享文件页显示。 |
| Workbench | 设置页“异地副本”：告警“存储桶未允许本站跨域上传”、“浏览器上传”一项（已允许 / 未允许 / 未能检查 + 检查时间），被拒时列出原因与规则。共享文件页：被拒时在列表上方显示同样的原因与规则；浏览器上传报网络错误且最近一次预检被拒时，提示改为“存储桶未允许本站跨域上传（原因），上传未完成”。 |

## 安全

- 预检不发送任何凭据；状态文件、事件和待办只含来源、桶名、地域和结论，不含签名 URL 或密钥（测试逐项断言）。
- 系统不修改桶配置（不在范围内，RAM 策略也没有这项权限）。

## 已知限制

- 只配回环监听时，经 `ssh -L` 用别的本地端口访问的来源无法预知，检查用的是监听端口。
- 待办只写入 `cardigan` 项目；其它部署形态没有该项目时只在页面显示。
