# C-536：上一轮结束后再送铃

- 派发、重试和显式复用会话均以当前终端的 `idle` / `done` 为可送状态，在真正写入前再检查。服务端代结束 Run 只释放业务占用，不是终端空闲凭据。
- 派发器为新 Run 记录通知流和首次发送；只接受该指派成功读取／确认对应流或对该 Run 的心跳作为回执。不以 `run_started` 或 `hc send` 返回成功代替回执。
- 使用既有派发确认窗口；确认已送但未获回执且原终端空闲时，只对原 Run 补送一次。发送边界前持久占用一次额度，再超时交 PM，附状态枚举；不重启、不强停、不改失活阈值。
- C-483 仍负责暂停、撤回及结果不明的发送。本卡不从旧记录推断丢铃，保留原目标与授权门禁。以临时数据库、可控终端和本机／远程目标回归业务结束先于终端结束、回执竞态和重启。
