# C-473：macOS 工作目录名与卷身份分开核验

- 采用方案 A。安装器、向导和机器就绪检查以 worker 的物理工作目录名核对配置；示例中 HOME、root 及其派生路径用 `/Users/...`，不在控制主机解析远程目录，也不把别名悄悄改写为受信路径。
- 安装器和运行时路径采样共用 Darwin 挂载点及卷号核对。保留 Linux 的挂载点、父子关系和设备检查，以及两端既有目录所有权、ACL、锁和剩余空间要求。
- 保留 `worker-git.py` 的仓库顶层、`git_state` 的目录验证和 Git 传输层的工作树注册路径精确匹配。规范根派生的 stage、仓库、工作树和构建目录与 Git 输出使用同一名称，不给其它目录或仓库增加例外。
- 用合成两种路径、卷不匹配及真实本地 Git 操作覆盖回归；补充在原目录迁移和停派发/恢复顺序。本地跑相关测试、增量构建、lint、依赖检查；部署后由张良在 C-472 记录真实 macOS 派发结果。
