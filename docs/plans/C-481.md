# C-481：建界面卡时定好状态与保存

1. `list_templates` 标出需要声明“状态与保存”的模板：前端实现或界面设计主产出由设计总监必需验收（包括内置 `ui`、`design`）。MCP 和 CLI 建卡共用领域校验。纯展示只填“无写入”；有写入则分别填写保存时机、离页行为、失败提示、读写一致性。普通卡无需声明。
2. 说明保存在卡上；有写入时，主产出和对应的设计验收工作项带上具体说明。先出设计稿的卡在设计评审确认；直接实现的卡在实现验收确认。复用绑定当前交付的必需审核，不加一道串行审核、不改模板版本、既有卡或工作项。
3. 设计规范写明设置类写入默认做法与 C-455/C-479 参考入口。前端和设计总监的默认角色规则引用同一规范，按既有部署升级与知会机制生效，不改工具权限。
4. 用契约覆盖缺项、无写入、写入及普通卡，测试建卡入口和角色规则；跑相关增量构建、domain test:types、定向测试、lint 和 check:deps。
