# C-441 · macOS 目录组结构修正

以本卡验收标准修正 C-437 的两处目录结构假设，不修改现场账号、组或系统权限。

1. 共用 `worker-primitives.py` 的 `checked_group` 接受 `RecordName` 包含预期名称和其它别名，保留名称/GID、UUID 交叉核对及显式成员拒绝。
2. everyone/localaccounts 仍为无嵌套根组。`_lpoperator` 必须至少直接嵌套其中之一；其余嵌套 UUID 逐一通过 `dsmemberutil checkmembership -U <账号> -X <组 UUID>` 核对递归成员关系，只接受明确的非成员结果。成员、查询失败或未知输出均拒绝。公共文件夹组的原规则不变。
3. 安装器、onboarding 探针和运行时隔离入口已有共用原语接线，沿用该路径。合成夹具采用 macOS 26 的 everyone 别名及 `_lpoperator → localaccounts / _lpadmin → admin` 结构；覆盖根组来源、额外非成员、直接成员、经 admin 递归成员、多条非根分支、查询异常及既有 Linux/公共组拒绝用例。
4. 本地只运行 host/runtime-herdr 的相关测试、增量构建、`pnpm lint` 和 `pnpm check:deps`；本地提交后请求同 SHA 远程预检。无快照变化。真实 Mac 接入由既有 H-123 跟进，本卡合成测试不作现场通过证据。
