# C-559：项目 worker 的非机密环境变量

1. 在控制主机私有 `runtime-workers.yaml` 的项目绑定读取可选 `env`。在使用前校验变量名、凭据和系统保留名、字符串类型与大小；非法配置整体拒绝，不回显值。空配置与省略相同，键顺序不改变绑定指纹；实际值变化使旧的目标引用和能力证据失效。
2. Run 使用现有启动材料中的环境映射（远程 `launch.json`、本机隔离账号启动脚本）；能力探测只在最终检查子进程加入该绑定的字面值。不修改 SSH、hc、Git、升级工具的环境，也不改变发布清单或 helper 协议。
3. 用合成绑定和探测子进程验证项目隔离、字面值、边界、旧绑定兼容与实际启动材料。在两种 worker 的接入文档中示例项目私有 Android 路径和非默认 adb 端口；不修改现场账号、端口或资源授权。
