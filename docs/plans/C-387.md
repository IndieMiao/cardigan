# C-387 快速补丁与部署托底

依据本卡验收标准，保持既有卡片固定版本及当前审核门禁。

1. 新增第五级内置 `fast_patch@1`，只有开发项，系统汇总完成申请。角色说明要求同会话子进程自审并记录参考结论。主机交付证据按有效高危路径判断；命中、人工高危或证据无法完整确认时，在同一事务改用 `dev@2` 并补齐代码审核与独立复核。保留已有身份，不重复生成工作项；检查及发布链不变。
2. 增加本机人专用 `deploy adopt <from> <to> --reason <说明>`、`deploy pin <sha> --reason <说明>` 和 `deploy unpin --reason <说明>`。认领绑定中心 main 历史中的精确区间和树；固定只接受中心 main 历史中的提交。操作单独审计，不制造检查通过或卡片合并事件。监督器沿用容量、构建、备份、停服、ready 和回滚合同；解除固定后恢复跟随 main。
3. 配置解析失败和监督器代码落后通过既有人工待办通道去重知会，同时提供安全错误文本；不升级监督器自身。
4. Git 候选准备只在冲突集合恰好为 `docs/development-plan.md` 时尝试双方保留的文本合并；混合冲突、二进制、文件模式变化或无法可靠合并时保留原冲突结果。解析不执行仓库过滤器、钩子或合并驱动；结果仍接受候选树合并检查。
5. AGENTS 与默认角色按需查阅开发方案。本卡不修改开发方案正文，不执行生产模板登记、人工部署操作或重启。

验证：定向领域契约、部署控制器/适配器/审计、CLI、Git 实仓冲突、服务端系统汇总及默认角色测试；领域测试类型检查、增量构建、lint 和依赖检查。正式交付前本地 commit，并取得同 SHA 远程预检通过。

## 实现边界与验证记录

- 第五级默认目录新增模板，原有卡片仍解析固定版本。交付时转换和系统汇总前的风险重核均在事务内执行；后续高危配置变化会撤销旧完成申请并补齐审核。未显式配置路径时使用已知默认值；缺少偏好集合、非法路径配置或不完整主机证据不认定为低风险。
- 认领是对明确的起止提交区间及目标树的人工审计，部署仍验证祖先关系与树。固定绑定人工审计事件，允许回退；不修改 main、不生成合并事件，不扩大 Agent 工具权限。固定操作与部署/检查共享互斥，忙时拒绝；重新固定相同版本可显式重试先前失败。关闭自动部署时不会因固定而启用。
- 解除固定后恢复原逐段证据核验。代码回退沿用部署前备份与失败恢复，不自动回退数据库；跨不兼容数据库版本的操作须由人先核对。监督器自身仍由主机维护。
- 冲突处理仅用于候选准备，原始树合并接口供审核归因和等价证明继续使用；无法确认共同文本、文件模式不符、二进制和混合冲突均返回原冲突。
- 本地定向集合覆盖 27 个测试文件、599 个用例；初次仅三份角色启动快照不符，已用 `-u` 更新并逐条核对为本次新增的两行角色说明，快照文件的 101 个用例通过。增量类型构建、领域测试类型检查、依赖检查通过；lint 通过，保留仓库既有警告。
- 使用临时 SQLite、临时 Git 仓库、假检查执行器及假服务验证；未执行生产认领、固定、解除固定、部署、重启、偏好或角色登记。本地没有运行全量测试或 e2e，远程同提交预检和最终合并检查另行记录。
