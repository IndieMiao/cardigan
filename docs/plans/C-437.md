# C-437 · macOS 隐式组兼容

以本卡验收标准修正 C-433 的账号检查，不修改账号、组或系统权限。

1. `worker-primitives.py` 统一目录服务和进程附加组校验。Darwin 仅豁免固定组名/GID：everyone/12、localaccounts/61、_lpoperator/100（本卡 Mac mini 现场报告）；Linux 继续只允许独占主组。
2. 读取固定本地 dscl plist，核对账号名/别名、UUID、UID/GID 与三组身份；拒绝显式账号名、UUID 成员和三组外的 NestedGroups，避免通过嵌套私有组绕过。读取有时限及 64 KiB 上限，解析或查询失败拒绝。进程保留旧外组仍拒绝。
3. 向导复用控制主机内联的共享原语，安装器去除重复的严格组判断；项目隔离入口沿用同一规则。不改 Linux、目录权限、sudo 拒绝和双向隔离验收要求。
4. 确定性夹具覆盖三组与内建嵌套、显式名字/别名/UUID、admin/staff/sharepoint 等外组、进程旧组、错名错号与不可读记录，贯穿向导、安装器和运行时入口。按受影响 host/runtime-herdr 相关测试、增量构建、lint、deps 验证，随后同 SHA 远程预检。

系统默认打印权限不等于管理员权限，也不能宣称没有任何系统权限。独占主组、私有目录模式和无 ACL 继续保护项目数据；现场须排除本机额外组授权并完成 B8 双向合成目录/socket 实测。本次确定性夹具不是实机证据。
