# C-437 · macOS 隐式组兼容

以本卡验收标准修正 C-433 的账号检查，不修改账号、组或系统权限。

1. `worker-primitives.py` 统一目录服务和进程附加组校验。Darwin 豁免固定组名/GID：everyone/12、localaccounts/61、_lpoperator/100；按 Q-870 另允许数字编号公共文件夹组的有限例外。Linux 继续只允许独占主组。
2. 读取固定本地 dscl plist，核对账号名/别名、UUID、UID/GID 与三组身份，通过 dsmemberutil 交叉核对组 UUID；拒绝显式名字/UUID 成员、伪造或重复身份。everyone/localaccounts 为无嵌套根组；_lpoperator 仅接受根组的直接嵌套。公共共享组必须无本账号直接成员、非空 NestedGroups 仅直接引用这两个根组，不递归继承。读取有时限及 64 KiB 上限，解析或查询失败拒绝。进程保留旧外组仍拒绝。
3. 向导复用控制主机内联的共享原语，安装器去除重复的严格组判断；项目隔离入口沿用同一规则。不改 Linux、目录权限、sudo 拒绝和双向隔离验收要求。
4. 三入口共用确定性合同矩阵，覆盖公共组的两种根继承、不同编号、名字/别名/UUID 显式成员、危险组继承 everyone、混合/未知/循环/间接嵌套、错名错号、重复/伪造 UUID 与不可读记录；保留三组和 Linux 回归。按受影响 host/runtime-herdr 相关测试、增量构建、lint、deps 验证，随后同 SHA 远程预检。

系统默认打印权限不等于管理员权限，也不能宣称没有任何系统权限。独占主组、私有目录模式和无 ACL 继续保护项目数据；现场须排除本机额外组授权并完成 B8 双向合成目录/socket 实测。本次确定性夹具不是实机证据。

## Q-870 执行边界

PM 已选择仅扩展 `com.apple.sharepoint.group.<数字>`，并同步卡片及验证项标准。管理、远程访问和其它项目组即使继承 everyone 仍拒绝。该决策仅调整软件接入检查，不授权修改现场账号、共享、ACL 或主机配置；现场打印/共享能力与双向隔离仍待实机证据。
