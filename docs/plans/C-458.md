# C-458：项目动态、项目快照按设计规范重构

依据 `docs/design/ui-guidelines.md`（卡片页为基准），只改界面，不改接口语义和权限。

1. 两页改为 `ui-workspace` + `PageHeader` + `PageToolbar`，右组 `RefreshGroup`（默认 30 秒，按页按项目保存，pending 不重复请求）。
2. 项目动态：卡片、发言方、事件类别、时间范围四个 `FilterSelect`，有筛选时出现“清除筛选”；事件列表改为 `DataTableLayout records` 表格（时间、发言方、事件、卡片、详情），按日期用 `GroupedTableBody` 分组，相邻同类系统事件仍在当天内合并；原始记录折叠在行下方。分页条沿用卡片页底部样式，保留“最新/更早的事件 · 本页 N 条”、“已经到底了”、“更早的事件”、“返回最新”。
3. 项目快照：五个概览计数移入页头 `PageStats`（链接与 tooltip 不变）；等你处理、等 Agent、进行中、审核与待合并、阻塞合成一张分组表（编号、标题、状态、下一步、原因，阻塞行原因为工作项标签）；最近交付一张表，摘要完整换行。工具栏新增分组筛选和搜索（仅前端过滤已读取的数据）。
4. 共享能力：`DataTableLayout` 增加 `records` / `label` / `data-nowrap` / `DataTableDetail`；新增 `layout/PageStatsLayout`；新增 `useRefreshInterval`。删除两页独占的旧样式（styles.css 只减不增），移除 ActivityPage 三条旧原生按钮豁免。规范补“列表型观察页”一节。
5. 验证：相关 Vitest、Web 增量构建、`pnpm lint`（含 check-ui）、`pnpm check:deps`、卡片页 44 图零像素回归；`test-support/observe-pages-screenshots.mjs` 以合成数据输出两页 1440/390 × 亮/暗前后截图、与卡片页同宽同主题并排图和测量 JSON。
