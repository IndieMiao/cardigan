# C-674 项目代号前缀（一）：登记与显示

## 代号

- 格式 `^[A-Z][A-Z0-9]{2,3}$`，全局唯一（`projects.code` 部分唯一索引），登记后不可改（触发器拒绝改写已登记的值）。
- `cardigan project create <id> --code <代号>`：`--code` 必填；缺省时报错并给出建议值。建议取项目名（名字没有英文字母时取编号）前三位字母或数字，已被占用时升为四位（同一词干加一位）。
- `cardigan project code [--set <代号>] [--project <p>]`：查看代号；尚未登记的项目可登记一次。
- 迁移 `project_codes` 加列并补登记：cardigan = CDG、sensen-godot = SEN（所有者建议值），其它已有项目按创建顺序取建议值。
- `Store.createProject` 省略 `code` 时登记建议值，仅供测试夹具和内部入口；人用的入口（命令行）必填。

## 完整编号

- 完整编号 = 代号-原编号：`SEN-C-34`、`CDG-Q-1291`、`SEN-C-34#12`。员工 `E-n`、成员 `M-n` 不加前缀。
- 存储不变：数据库仍按（项目、编号）存，不改写旧数据和旧评论。

## 显示

- 命令行 `needs-you`、`merge status` 的编号写完整编号；命令提示里的 `cardigan merge confirm C-n` 仍用短号（C-675 再让命令接受完整编号）。
- 飞书推送：webhook 文本与应用卡片标题以完整编号开头；给所有者的消息开头加 `[SEN-C-34]`（正文已以它开头时不重复）。
- Workbench：Needs You 页的编号标签显示完整编号；项目切换器显示 `名字（代号）`；看板、卡片页等项目内页面继续显示短号。
- 评论、正文里的 `SEN-C-34` 由服务端按代号到对应项目解析，存在时链接到该项目的卡片；短号 `C-34` 照旧按本项目解析，`SEN-C-34` 里的 `C-34` 不会被当成本项目的卡。
