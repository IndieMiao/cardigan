# C-440：按卡片页规范重建执行视图

依据 `docs/design/ui-guidelines.md`，保留现有接口、机器绑定优先级、筛选、员工/机器分组、排序、抽屉和运维动作。

1. 页头用 PageHeader/CapacitySummary，记录计数放在标题旁；删除工具栏和分组中的摘要说明行。
2. 工具栏由 PageToolbar、FilterSelect、SearchInput、DisplayMenu、RefreshGroup 和专用 ExecutionViewSwitch 组合。执行数据继续用“表格/卡片”模式，图标直接用卡片页的 ListIcon/BoardIcon；排序单独放在搜索之前，显示菜单只管理分组。
3. 刷新缺省为规范的 30 秒，保留已经保存的周期（包括关闭），按项目持久化，pending 时阻止重复请求。
4. 表格复用 DataTableLayout 的卡片表格策略：100% 宽、48rem 最小宽、内容决定列宽，横向滚动仅限容器；760px 以下仍用既有纵向执行记录。使用共享表头、排序箭头、状态、编号、身份行和卡片布局。
5. 拆出工具栏、行展示和详情，清理主页面旧骨架。运行相关 Web 测试、增量构建、lint/check-ui、deps；使用既有合成夹具实测三种模式、1440/390、亮/暗、筛选/分组/容量与键盘操作，输出同宽同主题的卡片页并排图。共享视觉基准 44 图保持零像素差异。
6. 本地提交后申请同 SHA 远程预检，通过后交代码审核和界面验收；完整测试和 e2e 留给主机。
