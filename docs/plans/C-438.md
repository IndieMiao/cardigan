# C-438 执行视图工具组重叠修复

仅修复执行视图筛选行右侧刷新周期、立即刷新与视图切换的布局；沿用卡片页对应工具组的 8px 间距，不调整其它页面样式或行为。

1. 使用 C-436 的固定内存夹具（8 个 Assignment、4 个 Run、4 张卡、2 台机器，非生产规模）重现并测量重叠。
2. 最小化修改执行页工具组结构，检查表格、分组、卡片及切换后状态；与同宽同主题卡片页对照。
3. 在 1440/390、深浅色下记录改前改后截图、控件与文字边界、相邻间距、换行和溢出；实际操作刷新周期、立即刷新和视图切换。
4. 本地运行相关 web 测试、增量构建、lint（含 check-ui）、check:deps；本地 commit 后请求同 SHA 远程预检，通过后交代码审核与界面验收。

## 实现与证据边界

刷新选择器采用卡片页相同的 label 包装，避免直接作为刷新组中可收缩的控件；刷新组与立即刷新按钮增加 `shrink-0`，明确保留完整文字所需宽度。继续使用共享布局的间距、换行和右对齐规则，不改共享 CSS。

当前基线的本地 Chromium 在指定宽度、主题和所有刷新周期下未复现用户截图的重叠，因此本卡交付的是局部防收缩修复。改前截图如实呈现该结果，不声明已定位用户浏览器的触发条件。浏览器回归核对修复后各模式、周期和实际切换时的边界、文字容纳、点击命中、间距及页面溢出；现场浏览器与物理触控未核。
