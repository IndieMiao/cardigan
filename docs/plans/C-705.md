# C-705 设备接入 1/6：一次性配对码与二维码

需求卡 CDG-C-693 拆解第 1 张。本卡只做配对协议、设备端命令和“配对码 → 向导草稿”；Workbench 确认页和体检报告是 C-707。

## 通道

新设备还没有账号，经 tailnet 访问 Workbench 同一个监听地址上的两个专用接口，不需要会话：

| 接口 | 调用方 | 作用 |
|---|---|---|
| `POST /api/device-pairings` `{device}` | 设备 | 上报设备信息，换一次性配对码、确认链接、二维码和设备轮询令牌 |
| `POST /api/device-pairings/status` `{device_token}` | 设备 | 查自己的配对状态：`pending` / `claimed` / `expired` |
| `POST /api/projects/:id/worker-wizards/pairing` `{code}` | 所有者（人类登录会话） | 核验配对码，生成现有“添加 worker”向导的预览草稿 |

设备上报的字段固定为 `hostname`、`os`（linux/darwin）、`arch`（x64/arm64）、`address`（tailnet 名称或地址）、`free_id`（设备上用户和组都空闲的数字编号，从 2000 起找）和可选的 `system`（系统名称），多余字段拒绝。仍走现有 Host/Origin 校验（设备把 Workbench 地址作为 Origin 发送）。

## 配对码规则

- 8 位，取自去掉易混字符的 31 个字符（约 39.6 bit），显示为 `XXXX-XXXX`，输入时忽略大小写、空格和连字符。
- 10 分钟内有效，只能用一次；用过或过期即失效。过期或已用的码再保留 30 分钟以便给出准确的错误码，之后按“不存在”处理。
- 只存在服务进程内存里，且只存 SHA-256 摘要；重启即全部作废。设备令牌同样只存摘要。
- 配对码只出现在请求体和确认链接的 `#` 片段里（浏览器不会把片段发给服务器），不进路径、查询串、访问日志、事件或时间线。审计事件 `worker_wizard_pairing_claimed` 只记随机的配对编号。
- 同时待确认的配对最多 16 个（`pairing_capacity`，429）。
- 同一成员连续输错 5 次按登录退避规则锁定（`pairing_rate_limited`，429，带 `Retry-After`）。

错误码：`pairing_code_invalid`（404，不存在或格式错误）、`pairing_code_expired`（410）、`pairing_code_used`（409）、`pairing_rate_limited`（429）。

## 生成草稿

核验通过后，按设备信息生成向导表单（机器编号取主机名，账号 `cg_<项目>`，uid/gid 取设备上报的空闲编号，端口 22，MCP 地址取向导现有的默认值），交给与手工创建完全相同的 `workerWizardForm → 注册表兼容检查 → 配置预览` 路径。结果是 `preview` 阶段的向导会话，后续确认、检查和“开启远程派活”仍是原有的单独步骤。核验、生成和作废在同一个同步回合里完成，所以并发提交同一个码只有一个成功。

生成失败（例如主机没有可用的 MCP 地址）时配对码不作废，错误码沿用向导原有的，`details.form` 带回设备信息，方便在向导里手工补全。

## 设备端命令

`apps/web/public/pair-device.py`（只用 Python 标准库，随 Workbench 静态文件发布）：

```sh
curl -fsS https://<workbench>/pair-device.py | python3 - https://<workbench>
```

读取 `tailscale status --json` 得到本机 tailnet 名称；没装或没登录时给出指引并退出，不代装（也可用 `--address` 指定）。显示二维码（`--light` 适配浅色终端）、配对码、确认链接和有效期，然后每 3 秒轮询一次，确认后退出。不需要 sudo，不改动设备。

二维码由服务端生成（`apps/server/src/web/qr.ts`，字节模式、纠错等级 M、版本 1–6），内容是 `<Workbench>/#/pair/<配对码>`。

## 不变的部分

- `cardigan worker add/check/status/...` CLI 和手工向导的接口、校验与行为不变；已接入机器和派发不受影响。
- 不新增合并门禁或卡片流转阻塞；接入失败只影响这台新设备。
