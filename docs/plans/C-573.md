# C-573 空闲会话安全接续

依据 Q-1126、C-573#12，目标是恢复积压通知，不把“超过 15 分钟”当作停止授权。

1. 巡检和运维使用同一条原因记录。已结束轮次与从未派发的后继分开；业务等待、人工停止、发送中、其它在途执行仍阻止接续。
2. 仅在登记的工作树做本地快照。保持工作分支、真实索引与文件不变；备份校验失败不得发信号。检查机与会话必须属于同一个登记目标。
3. 只对当前能证实归属、独占且空闲的受管执行使用受限停机入口。名字、地址、备份、无活动或查询返回未找到均不能证明退出；没有退出证据不注销旧执行、不启后继。
4. 证据不足，原通知保留，按故障去重交给主机运维；15 分钟仍无承接提醒 PM Office。接续、备份、移交分别记账；24 小时统计必须在部署后采集。
5. 回放覆盖退役保留、本机与远程未派发后继、陈旧运行记录、脏工作树、等待与停止竞争；不操作现场员工会话。

阶段记录：已对齐排队后继与停机结算的退出证据；精确查询也返回“找不到”时保留原通知与排队项。远端取证限定登记项目、指派所属机器及运行时指纹，取证不增加停止权限。移交超时按原故障去重通知 PM Office。备份引用原型仅固定已在登记作者分支上的提交，尚未接入调度；不能把它当成脏工作树已备份。
