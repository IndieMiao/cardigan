# 主机 CPU 录制边界与操作说明（C-344）

赵云；对应 C-344／W-1158，基线 `e18cc5468f1a0c3fd7283958131e1e71d9d4a1dc`。本轮是等待人正式拍数值前的基础交付，尚不能用于生产录制，也没有申请整卡完成。后续软件合入部署、操作单受审就绪后，才由张良执行生产后台 60 秒采集及热点前十对照；该现场步骤尚未执行。

## 当前可执行步骤

本版本没有 CPU 录制命令、私有请求文件消费者、Web/MCP 入口或生产默认限制。不要通过修改生产启动脚本、添加调试参数、重启服务来试用本基础交付。既有 `preference tick-profile` 仍只控制聚合计时，不会触发 CPU 采集。

在本交付检出中运行以下隔离验证，不读取生产库、主机私有配置或真实 profile：

```sh
pnpm exec tsc -b packages/host
pnpm exec vitest run packages/host/src/cpu-profile-recorder.test.ts --maxWorkers=1
pnpm check:deps
```

测试使用显式注入的合成边界及短录制，不代表生产规则获批。真实 Session 用例只做一次短采样，等待正常定时器，不空转或制造负载；制品只留测试进程内存，不落盘、不上传。

## 最薄完整实现边界（后续接线方案）

1. 主机操作者通过人专用本机 CLI 提交一次性请求。入口沿用既有 Token 模式拒绝人专用命令的鉴权边界，不能因指定参数或角色而回退成人。数据和命令只在原主机私有目录，不进入项目偏好、数据库、Agent 运行目录、卡片附件或日志正文。生产仍依赖既有主机与 Agent 操作系统账号隔离，不能靠清除 Token 证明人身份。
2. 请求绑定当前角色（Web 或后台）、完整 release SHA、PID、启动随机代次及唯一请求号；两者录制各生成独立请求。目标身份只来自运行进程在私有目录发布的登记，不接受客户端提供任意 PID、路径或 release。部署后旧请求失效；相同进程不重复消费已领取请求。整组目标校验失败不发布部分请求。
3. 各进程沿既有工作边界动态读可信请求，无新增巡检周期或远程监听。后台在现有 tick 边界，Web 在现有请求边界；空闲 Web 等到下一次正常请求，不额外轮询或制造请求流量。配置异常固定分类拒绝，不静默放宽权限或使用旧请求。
4. `node:inspector/promises` 的进程内 Session 顺序 enable、setSamplingInterval、start、stop、disable、disconnect；不调用 `inspector.open`，不开放调试端口。互斥覆盖启动、采样、停止及后续落盘；每个进程最多一个录制。采集基础现在已有进程级互斥，后续控制器须把互斥延续到落盘结束。
5. 正常停止、可处理的 SIGTERM／部署关闭先停止准入并调用 Profiler.stop；成功取得完整数据、清理 Session 且符合原权限／配额约束时，原子发布完整制品，即便实际窗口短于请求时长也须标明停止原因。显式取消则丢弃结果；异常只记录固定阶段和类别，不回显 inspector 对象或底层错误。强制杀进程无法运行清理；后续文件协议必须使这种情况下也只有临时文件，不能伪装成完整 profile。此语义采用 C-344#12 的验收细化。
6. 固定主机私有目录以目录描述符锚定；逐级拒绝符号链接，校验属主、目录权限 0700、文件权限 0600、普通文件及单硬链接，并在使用前后核对目录身份／替换。临时文件独占创建、完整写入并同步后再原子发布；不覆盖既有制品、不跟随链接。文件名包含角色、完整 release SHA、PID、UTC 时间及随机标识。实现须在不支持所需安全语义的平台明确拒绝，不能退回普通路径读写。
7. 每角色独立配额目录避免 Web／后台并行竞争共用预算；配额计入临时写入预留。容量不足拒绝新录制，停止后输出超额则拒绝发布；不自行删除已有 profile。异常临时残留由主机操作者核实身份后处理，自动清理仅限本次持有且已核对身份的临时文件。

## 待人正式决定的数值候选

下表是提案，不是已授权生产默认；PM 已按此表提交正式拍板 Q-646，目前待人答复。默认状态始终不录制；后续实现只采用正式答复，无答复不装配生产触发能力。

| 项目 | 候选 | 行为与取舍 |
|---|---|---|
| 录制时长默认值 | 60 秒 | 与后续生产验收窗口一致，但本卡文字中的建议不能代替人答复。 |
| 录制时长范围 | 1～120 整数秒 | 拒绝范围外请求，不截断或自动修正。 |
| 采样间隔默认值 | 1000 微秒 | 约每秒 1000 次，实际开销须后续对比验证。 |
| 采样间隔范围 | 1000～10000 整数微秒 | 拒绝更密集或超范围采样，不由配置放宽。 |
| 保留数量 | 每角色最多 10 个完整文件 | 两角色合计最多 20 个；启动前预留一个名额，不自动淘汰。 |
| 磁盘总量 | 每角色 128 MiB，两者合计 256 MiB | 单个文件也不得超过 128 MiB；包含临时文件／在途预留。输出前按 UTF-8 字节核验，超额不发布。 |
| 满额行为 | 拒绝新录制／超额结果不发布 | 保留旧文件，主机操作者人工检查后另行清理；本提案不请求自动删除授权。 |

时长是正常事件循环能够运行定时器时的请求窗口，不是阻塞事件循环下的硬实时保证；stop 回调可能延迟。磁盘上限也不是 inspector 在内存生成 profile 时的堆上限。后续正常合成工作对比必须报告这些实证限制，不能把候选数值称为已验证的低开销。

## 已有采集基础及验证边界

`packages/host/src/cpu-profile-recorder.ts` 目前不从 host 包入口导出，也没有生产调用方。必须显式注入限制和请求值才能采集；构造和空闲关闭不创建 Session。限制对象复制保存，非法值在连接前拒绝。互斥跨该模块的 recorder 实例，覆盖异步 enable 和 disable。正常停止／关闭等待 stop、disable、disconnect，成功时返回完整内存数据及停止原因，留给后续控制器安全落盘；在 start 前已关闭则不开始采样。显式取消及清理异常不返回可发布结果；底层异常只转成固定类别。若 disconnect 本身失败，不能证明采集器已释放，则保持进程录制互斥，不允许再建 Session，进程退出前不恢复。此基础不承担 CLI 身份、文件权限、运行进程登记或落盘安全校验，不能单独作为完成功能使用。

本轮定向用例覆盖：无请求无采样、输入边界、进程内互斥、启动过程中关闭、显式取消丢弃、正常停止／关闭返回完整内存数据、停止后关闭竞态、Session 各阶段异常和重用、真实 Session 不开放端口。后续仍须补：host 私有设置／CLI Token 拒绝、Web／后台装配和精确目标绑定、动态读取／重放拒绝、符号／硬链接／目录替换负例、0700／0600、原子完整发布、配额，以及真实 SIGTERM、SIGKILL／磁盘满的残留和恢复，以及直接调用方 C-265 的旧行为。

后续有界合成实验使用同一软件、同一合成来源／规模，顺序比较关闭和开启时进程 CPU 与事件循环 p99，不读生产数据、不空转或压测、不扩大 worker 数；原始合成 profile 留隔离目录，报告只写聚合数据。全量与端到端由主机合并检查负责。当前尚无完整装配，未做该开销对比，不能宣称开销验收通过。

## 数据处理与生产步骤前置

采集代码不读取环境变量、配置或 Token 正文，也不把它们添加到 profile。CPU profile 本身可能包含函数名、文件路径、动态脚本名称／URL；运行中代码的这些名称可能带任意字符串，不能保证自动脱敏或保证所有内容绝无凭据。制品仅主机内部使用，不自动上传、不通过 Agent/MCP/Workbench 读取；任何外传都须主机操作者先人工检查。

后续可执行生产操作单须在数值正式批准、软件接线和文件负例通过后更新至同版命令，逐步说明：核实合入及部署 ready → 核对实际运行身份与私有目录权限 → 提交一次性请求 → 在原边界消费并录制 → 只由主机操作者核对完整制品身份／容量 → 人工检查内容 → 张良报告热点前十及与原临时重启取证的对照。当前文档不是生产操作授权，不执行这些步骤。

C-339 生产复测所报 retry_dispatched 约 0.14 秒／分钟、后台 CPU 约 81～83% 是采集动机；墙钟 span 包含 await 且可能嵌套，不能和进程 CPU 秒相减证明未覆盖比例或根因。本卡不修热点。
