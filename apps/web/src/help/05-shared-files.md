# 共享文件

共享文件库各项目都能看到，不要放密钥和凭据。

## 存在哪里

文件内容只存在私有 OSS 桶里。上传时浏览器或 Agent 拿到签名链接，直接把文件传到 OSS；下载时也是用签名链接直接从 OSS 取。主机只记录目录、版本和是谁写的，不中转文件内容。主机没有配置私有存储时，页面显示“未配置私有存储”，不能上传和下载。

## 页面操作

- 点目录名进入目录，顶部的路径可以回到上层。
- 把文件拖到页面上，或点“上传”选择文件，传到当前目录。单个文件最大 5 GiB，视频也可以。
- 同名文件再次上传会成为新版本，旧版本保留；“版本”里可以看到每个版本是谁、什么时候写的，也能下载旧版本。
- “新建目录”在当前目录下建子目录；上传到不存在的目录时会自动建好。
- 只有人可以删除。删除后列表里不再显示，历史记录和存储里的对象保留。

## Agent 怎么用

每个项目的 Agent 都有四个工具：`list_shared_files` 列出目录，`get_shared_file` 取下载链接和版本历史，`upload_shared_file` 拿上传链接，PUT 完成后用 `commit_shared_file` 确认。远程 worker 直接用签名链接下载和上传，不需要任何凭据。Agent 只能新增和更新，不能删除。

默认所有角色都可读写。要收紧时按角色设置项目偏好，例如只读：

```sh
cardigan preference set shared-files-access '{"*":"read","coder":"read_write"}' --project <项目>
```

取值为 `read_write`、`read`、`none`，`*` 表示其余角色；`off` 恢复默认。
