# 查找工作和记录

## 需要你处理的事

从侧栏的 **Needs You** 查看待拍板、人工待办和需要关注的事项。处理前先看问题、影响和关联卡片；暂缓的合并确认到期后会重新出现。

各标签页的每一项都是同一种行：左边是卡号、事项编号和标题（有人话概述时显示在标题下）；右边是等待时间、状态和主操作。点行首的箭头展开详情，点“处理”会展开详情并把焦点移到要处理的第一个控件（方案、执行结果或合并操作）；不需要你处理的事项显示“查看”；拍板、合并、退回、暂缓和执行结果都在详情里提交，与以前相同。

- **合并确认** 里的“PM 代确认中的合并”不需要你处理；想自己拍板时可以接手处理，不用关闭“合并由 PM 代确认”。
- **待你执行** 里的“待主机操作”交给主机操作员，“交给张良”由张良执行，都不需要你处理。
- 页头“N 件事等你处理”、侧栏 Needs You 角标和待拍板、合并确认、待你执行三个标签上的数字用同一个口径：只算要你本人处理的事。交给张良、PM 分拣中、PM 代确认和待主机操作的事项照常列出，但不计入这些数字；卡片顶部也按同一归属写“等你执行”“交给张良”“PM 处理中”或“待主机操作”，只有你要处理的才有操作按钮。
- **稍后** 是还没到时机的事项，条件满足后会自动出现在对应标签页；不再需要的待办可以直接关闭，关闭不记为完成。
- **知会** 是系统、PM 和外接维护者的处理结果及提醒，不阻塞工作；有疑问可在卡片里追问。

## 查看目标与进度

从 **卡片** 进入看板或列表，再打开具体卡片。卡片详情中可以查看工作项、交付、审核和时间线。一个目标可以有多项工作和多次交付，审核结论要对应当前版本。

概览里的“卡片依赖”图从左到右排列前置和后续卡片。点一个节点（或聚焦后按回车、空格）会在旁边弹出它的状态、当前负责人、进行中的工作项和与当前卡的关系，页面不跳转；要前往那张卡，点浮层里的“打开卡片”。图比区域宽或高时（图最高占半屏，超出部分在图内滚动），按住鼠标左键在图上拖动即可平移（移动超过约 4 像素算拖动，不会弹出浮层），也可以用滚动条、触控板、手指拖动，或在节点聚焦时按方向键。

## 提出新需求

在 **卡片** 页右上角点“新建需求”，写下标题和粗略描述，可以附上图片、PDF 等文件，点“创建”后进入需求卡流程：Office 会澄清问题、给出拆解方案，你确认后再开子卡。人默认只能开需求卡；所有者在 **设置 → 偏好 → 需谨慎** 的“人可开的卡片模板”里放开其它模板后，对话框里才会出现模板选择。命令行 `cardigan card create` 遵守同样的限制。

## 查看执行和历史

- **执行视图**：查看谁在运行、排队或等待，以及所在的责任上下文。
- **项目动态**：浏览项目最近的变化。
- **拍板记录**：查阅问题及其决定。
- **项目快照**：了解项目当前情况。
- **发版说明**：按版本查看、填写和复制发版说明，见“发版说明”一篇。

窄屏下，点顶栏的“打开导航”展开侧栏。帮助入口位于“登出”上方；选择目录中的文章即可切换内容，浏览器后退可返回前一篇。
