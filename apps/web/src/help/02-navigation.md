# 查找工作和记录

## 需要你处理的事

从侧栏的 **Needs You** 查看待拍板、人工待办和需要关注的事项。处理前先看问题、影响和关联卡片；暂缓的合并确认到期后会重新出现。

## 查看目标与进度

从 **卡片** 进入看板或列表，再打开具体卡片。卡片详情中可以查看工作项、交付、审核和时间线。一个目标可以有多项工作和多次交付，审核结论要对应当前版本。

## 查看执行和历史

- **执行视图**：查看谁在运行、排队或等待，以及所在的责任上下文。
- **项目动态**：浏览项目最近的变化。
- **拍板记录**：查阅问题及其决定。
- **项目快照**：了解项目当前情况。

窄屏下，点顶栏的“打开导航”展开侧栏。帮助入口位于“登出”上方；选择目录中的文章即可切换内容，浏览器后退可返回前一篇。
