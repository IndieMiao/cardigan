# 执行视图与会话维护

## 查看维护原因

执行视图的列表和卡片显示空闲候选、回收等待、超时、无法确认及角色发布或冲突等需要关注的原因。正常运行、近期活动、尚无会话等观察不额外占一行；点击员工的 Assignment 编号，可在详情中查看完整维护原因、最近评估时间和候选阈值。

## 空闲候选与自动回收

内部非常驻、非外接的工作项会话，没有未结束的执行，最近执行结束和最后工具活动均严格超过候选阈值（默认 60 分钟，可配置），且未暂停、停止或被接入及主机操作锁占用时，才可能自动回收。空闲候选只表示控制面条件满足，不代表会话已经退出。

**原生 hc attach、桌面接入以及终端输入输出目前无法完整观测。即使显示空闲候选，自动回收仍可能打断这些入口的交互或未被控制面记录的后台工作。** 现有 Cardigan 接入锁不能保护所有原生入口，不保证原子无损回收。

回收只尝试挂断和正常终止，不升级强杀。超时或无法确认退出时保留会话引用并退避等待；“等待确认会话退出”“终止超时”都不表示回收成功。确认退出后保留工作项身份、工作区、分支和文件，下次合法唤醒创建新会话；暂停或停止项不会因此自动恢复。
