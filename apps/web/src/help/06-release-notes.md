# 发版说明

**发版说明** 页集中展示本项目每个已发布版本的更新内容，最新发布的版本在最上面。每行有版本号、发布时间、最近一次修改的作者和正文。

- 版本来自项目的版本发布（制品外发）。发布了但还没有写说明的版本显示“未填写”；一次都没有发布过时页面只显示“没有发布的版本”。
- 点“填写”或“编辑”打开编辑框，写完点“保存”，整段正文一次提交，输入过程中不会自动保存。保存失败时提示留在编辑框里，已写的内容不丢，可以直接重试。
- 有没保存的修改时，点“取消”、按 Esc 或点编辑框外面会先问一次是否放弃；关闭或刷新浏览器标签页时由浏览器询问。
- 如果打开编辑框之后别人（例如 PM）已经改过这条说明，保存会被拒绝并提示已是第几版，避免覆盖别人的修改；先复制自己写的内容，取消后重新打开再改。
- “复制”把正文原文（纯文本）放进剪贴板，可以直接贴到商店或公告里。正文最多 4000 字。

PM 发版时可以在 `publish_artifact` 里顺带写说明，也可以之后用 `write_release_note` 补写或修改；没写说明不影响发布和合并。每次修改都会留下记录。
